# @native-dates/setup

Interactive coding-agent setup CLI for [`native-dates`](https://www.npmjs.com/package/native-dates).

```bash
npx @native-dates/setup@latest
```

Installs `native-dates`, links its agent skills into `.agents/skills` and `.claude/skills` (or installs agent plugins with `--global`), and adds a pointer in `AGENTS.md`.
