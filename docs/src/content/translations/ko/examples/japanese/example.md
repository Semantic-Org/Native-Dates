`configure({ locale: 'ja' })`를 한 번 호출하면 모든 텍스트 미리보기와 포맷 프리셋에 일본어가 적용됩니다. 기본 프리셋은 앞 0이 없는 숫자와 한자 단위를 조합하며, `day.yearMonth`는 월간 제목용으로 일 단위를 떼어냅니다.

날짜 범위와 자정을 넘기는 `timeRange()` 값도 설정된 로케일을 자동으로 따릅니다. 두 범위 모두 자정 전후에 임의의 달력 날짜를 끼워 넣지 않고 일본식 물결표로 시작과 끝을 연결합니다.

다른 역법을 선택할 때만 로케일 태그를 전달하세요. `'ja-u-ca-japanese'`를 전달하면 일본 연호력으로 포맷하며 각 연호의 첫해는 `元年`으로 출력합니다.
