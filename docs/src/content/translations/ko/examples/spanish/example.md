`configure()`에 `'es'`를 한 번 설정하면 앱 전체에 스페인어 포맷과 일-월-연 순 느슨한 파싱이 적용됩니다. 전체 날짜에서는 요일과 월명을 소문자로 유지하며 일, 월, 연을 ‘de’로 연결합니다.

날짜 범위는 로케일을 다시 지정하지 않아도 `range.format('long')`이 공통 부분을 축약합니다. 5월 안의 범위는 “de mayo de 2026”을 한 번만 출력하고, 6월로 넘어가면 대시 양쪽에 각 월명을 출력합니다.

달력 헤더에서는 `start.yearMonth`를 읽어 연결어 ‘de’가 유지된 “mayo de 2026”을 포맷합니다.

`'es'`는 날짜를 일-월-연 순으로 쓰므로 `date(typed.value, { loose: true })`는 “01/05/2026”을 5월 1일로 파싱하고, 잘못된 텍스트에서는 `null`을 반환합니다.
