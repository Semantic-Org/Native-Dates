`configure({ locale: 'ko' })`를 한 번 설정하면 모든 `.text` 속성과 `format()` 호출에 한국어 표준 날짜 표기와 띄어쓰기가 그대로 적용됩니다.

`range.format('long')`을 호출하면 같은 연·월 범위에서는 중복되는 앞부분을 생략해 `2026년 5월 1일~5일` 형태로 정리하고, 월이 바뀌는 구간에서는 끝 날짜의 월을 자동으로 복원합니다. 별도 분기나 문자열 조합 없이 월 경계를 안전하게 처리할 수 있습니다.

12시간제 시각은 `hour12: true` 옵션만으로 `오전`/`오후` 전치 형식을 그대로 출력하며, 달력 헤더나 월별 요약에는 `day.yearMonth.text`를 읽어 연월 제목을 깔끔하게 만들 수 있습니다.
