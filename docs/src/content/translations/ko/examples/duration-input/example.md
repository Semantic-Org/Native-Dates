사용자 입력을 `duration()`에 전달하면 `'90 minutes'`나 `'2 weeks and 3 days'` 같은 영어 기간 표현과 ISO 8601 문자열을 하나의 구조화된 값으로 파싱합니다.

그다음 `format()`으로 기간을 읽기 쉬운 문구로 출력하고, `total('hours')`로 전체 기간을 소수점 포함 시간 값으로 환산합니다. 문자열 보간을 사용하면 데이터베이스나 API 페이로드에 바로 쓸 수 있는 표준 ISO 8601 형식이 출력됩니다.

읽을 수 없는 입력은 예외를 던지며, 개발 모드에서 제공되는 영어 `error.message`가 잘못된 입력을 짚어 주고 유효한 예시를 화면에 바로 표시합니다.
