각 매장은 현지 시각 기준의 `timeRange(open, close)`로 영업시간을 정의합니다. 마감 시각이 개점 시각보다 이르면 범위가 자동으로 자정을 넘겨 이어집니다.

사용자가 선택한 시각에 `today().at(input.value)`로 오늘의 `DateTime` 시점을 만든 뒤, `in(place.zone)`으로 각 매장 시간대의 시점으로 변환합니다.

그런 다음 `hours.contains(local.time)`으로 현지 시각이 영업 범위에 포함되는지 확인하면, 심야 구간 예외 처리나 수동 UTC 계산 없이 영업 여부를 바로 판별할 수 있습니다.
