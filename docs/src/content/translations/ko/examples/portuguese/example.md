`configure()`에 `'pt-BR'`을 한 번 설정하면 모든 곳에 브라질 포르투갈어 포맷과 일-월-연 순 느슨한 파싱이 적용됩니다. 시간대가 있는 시점을 포맷하면 “sexta-feira” 같은 하이픈 요일, 소문자 월명, 시각 앞의 축약 전치사 ‘às’가 그대로 유지됩니다.

`range.format('long')`은 여러 날 범위에서 공통 월과 연도를 축약합니다. 같은 5월 안의 범위는 양쪽 날짜에 반복하지 않고 끝에 “de maio de 2026”을 한 번만 출력합니다.

`start.yearMonth`를 읽으면 청구 월이나 달력 월만 분리하면서도 “maio de 2026”의 전치사 ‘de’를 유지합니다.

`'pt-BR'`은 날짜를 일-월-연 순으로 쓰므로 `date(typed.value, { loose: true })`는 “08/05/2026”을 5월 8일로 파싱하고, 잘못된 텍스트에서는 `null`을 반환합니다.
