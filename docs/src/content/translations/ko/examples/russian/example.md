`configure({ locale: 'ru' })`를 한 번 호출하면 모든 곳에 러시아어 월명 격변화와 복수형 어미가 적용됩니다. `day.yearMonth.text`를 읽으면 제목용 단독 주격 월명을 선택하고, 전체 날짜에서는 자동으로 생격으로 전환합니다.

날짜 범위는 엔 대시로 묶어 공통 월과 연도를 축약합니다. `span.text`를 읽으면 수동 템플릿 없이도 공통 월명의 생격을 유지해 `1–5 мая 2026 г.`를 출력합니다.

`days(total).text`는 러시아어의 3단계 복수형 규칙을 기간 수량에 바로 적용합니다. 21처럼 1로 끝나는 수는 단수 `день`을 반환하고, 11부터 14까지의 수는 예외적으로 복수 생격을 취합니다.
