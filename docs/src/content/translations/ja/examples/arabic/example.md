`configure({ locale: 'ar-EG' })` を一度呼び出すだけで、すべての値にアラビア語の複数形と東部アラビア数字が適用されます。`days(2).text` を読み取ると、数字を一切付けずに双数形の名詞だけで出力されます。

アプリ全体の既定ロケールは維持したまま、特定の値とそこから派生する範囲だけを西洋数字とモロッコの月名にしたい場合は、`.locale('ar-MA')` をチェーンします。

`'ar-SA-u-ca-islamic-umalqura'` を渡すと、任意の西暦日付をサウジアラビアのウンム・アルクラー暦（ヒジュラ暦）へ変換できます。同時に `day.monthDay` を使えば、西暦の月日も並べて表示できます。

左から右へ読む（LTR）ページ内にアラビア語テキストを埋め込む際は、フォーマット結果を `<bdi>` で囲むと、数字や範囲のダッシュが右から左の語順を保てます。
