`configure()` に `'pt-BR'` を一度設定すると、ブラジル・ポルトガル語のフォーマットと日優先の loose モード解析がアプリ全体に適用されます。タイムゾーン付きの日時をフォーマットすると、「sexta-feira」のようなハイフン付き曜日、小文字の月名、時刻の直前のクラージ「às」がそのまま出力されます。

複数日にまたがる範囲は、`range.format('long')` で共通の月と年が省略されます。5月内に収まる範囲では「de maio de 2026」が両日に繰り返されず、末尾に1回だけ出力されます。

`start.yearMonth` を読み取ると請求月やカレンダー月を取り出せ、「maio de 2026」の前置詞「de」も正しく維持されます。

`'pt-BR'` では日付を日・月・年順で書くため、`date(typed.value, { loose: true })` は「08/05/2026」を5月8日として解析し、不正な文字列では `null` を返します。
