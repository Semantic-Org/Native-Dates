中国語や日本語とは異なり、韓国語の正書法では年・月・日の助数詞の後ろにスペースを入れます。`configure({ locale: 'ko' })` を一度呼び出すと、すべての `.text` プロパティと `format()` 呼び出しにこの分かち書きが適用されます。

`range.format('long')` を呼び出すと、両端の日の数字に `일` を残したまま、チルダ区切りで共通の年月を省略します。月をまたぐ範囲になると、終了側の月の助数詞が自動的に補われます。

12時間制の時刻では、韓国語の午前・午後表記が時の数字の前に置かれます。また、`day.yearMonth.text` を読み取ると末尾の日を省いた月見出しをきれいにフォーマットできます。
