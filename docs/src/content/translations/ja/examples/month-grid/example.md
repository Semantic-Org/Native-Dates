カレンダーの状態は単一の `yearMonth(today())` で管理します。前後の月への移動は、`minus()` または `plus()` を1回呼び出すだけです。

月初と月末の前後の空きマスを埋めるため、`startOf('week')` と `endOf('week')` で現在のロケールの週の始まりに合わせて日付範囲を広げます。

その範囲に対して `every('day')` を呼び出すと、すべての日セルが順番に得られます。各セルのクラス付与には `day.isToday()` と `day.isWeekend()` をそのまま使えます。
