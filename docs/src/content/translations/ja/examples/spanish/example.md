`configure()` に `'es'` を一度設定すると、スペイン語のフォーマットと日優先の loose モード解析がアプリ全体に適用されます。完全な日付では曜日と月名が小文字のまま保たれ、日・月・年が前置詞「de」でつながります。

日付範囲は、ロケールを再指定しなくても `range.format('long')` で共通部分が省略されます。5月内の範囲では「de mayo de 2026」が1回だけ出力され、6月をまたぐとダッシュの両側にそれぞれの月名が表示されます。

カレンダー見出しには `start.yearMonth` を使えば、接続語「de」を保った「mayo de 2026」をフォーマットできます。

`'es'` では日付を日・月・年順で書くため、`date(typed.value, { loose: true })` は「01/05/2026」を5月1日として解析し、不正な文字列では `null` を返します。
