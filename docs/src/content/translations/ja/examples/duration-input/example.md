ユーザー入力を `duration()` に渡すと、日常的な英語の単位表現と ISO 8601 文字列の両方を1つの構造化された値として解析できます。

その値から `format()` で期間を文章表記に整形し、`total('hours')` で合計時間数の数値に変換できます。また、文字列に埋め込むとデータベースや API ペイロード向けの標準的な ISO 8601 形式が出力されます。

解釈できない入力ではエラーがスローされ、`error.message` が不正な入力箇所と有効な記述例をページ上にそのまま示します。
