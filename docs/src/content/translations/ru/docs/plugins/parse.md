## Разбор по шаблону формата

По умолчанию ядро строго разбирает строки ISO 8601, а [`@native-dates/plugins/loose`](/plugins/loose/) читает текст в свободной форме для активной локали. Импорт этого плагина добавляет опцию `{ format }` для строк фиксированного формата — например, банковских выгрузок и серверных логов.

```js title="parse.js"
import '@native-dates/plugins/parse';
import { date, datetime, monthDay, time, yearMonth } from 'native-dates';

date('24112026', { format: 'DDMMYYYY' }).toString(); // '2026-11-24'
datetime('24/Nov/2026:12:40:01 -0500', {
  format: 'DD/MMM/YYYY:HH:mm:ss ZZ',
  zone: 'America/New_York',
  locale: 'en-US',
}).toString(); // '2026-11-24T17:40:01.000Z'
time('1430', { format: 'HHmm' }).toString(); // '14:30:00'
yearMonth('11/2026', { format: 'MM/YYYY' }).toString(); // '2026-11'
monthDay('29/02', { format: 'DD/MM' }).toString(); // '02-29'
```

Строгий разбор ISO остаётся поведением по умолчанию везде, где опция формата не передана. Вызов любой фабричной функции с `{ format }` до импорта этого плагина выбрасывает ошибку [`missingPlugin`](/api/errors/#plugins).

## Строгое сопоставление и именованные форматы

Шаблоны используют основной [набор токенов](/guides/formatting/#token-patterns). Токены фиксированной ширины требуют точного количества цифр, а литеральный текст должен совпадать по всей строке с учётом регистра.

При передаче невозможных дат вроде 30 февраля и несовпадающих дней недели выбрасывается ошибка вместо переноса на следующие дни. Повторяющиеся токены и противоречивые поля 12-часового и 24-часового формата отклоняются точно так же.

```js
import { configure, date, dateRange } from 'native-dates';

date('Tue 2026-11-24', { format: 'ddd YYYY-MM-DD', locale: 'en-US' }).toString();
// '2026-11-24'
date('6/9/26', { format: 'D/M/YY' }).toString(); // '2026-09-06'

configure({ formats: { bank: 'DDMMYYYY' } });
date('24112026', { format: 'bank' }).toString(); // '2026-11-24'
dateRange('24112026', '30112026', { format: 'bank' }).toString();
// '2026-11-24/2026-11-30'
configure({ formats: null });
```

Именованные шаблоны, зарегистрированные в [`configure()`](/api/configure/), работают и для разбора, и для форматирования. Фабричные функции диапазонов передают опцию формата обеим границам, в том числе когда вторым аргументом указана длительность.

## Локализованные названия и порядковые числа

Названия месяцев, дней недели, частей суток и порядковые маркеры следуют активной локали. Самостоятельные и склонённые формы месяцев распознаются без учёта регистра, поэтому русские и греческие даты разбираются без дополнительных правил.

Активная локаль выбирается в том же порядке, что и при форматировании: сначала опция в конкретном вызове, затем настройки [`configure()`](/api/configure/), а при их отсутствии — локаль среды выполнения по умолчанию. Передавайте локаль явно, если входные строки всегда приходят на одном языке — например, из английских серверных логов.

```js
import { date, time, yearMonth } from 'native-dates';

date('November 24th, 2026', { format: 'MMMM Do, YYYY', locale: 'en-US' }).toString();
// '2026-11-24'
date('6 ноября 2026', { format: 'D MMMM YYYY', locale: 'ru' }).toString();
// '2026-11-06'
date('6. November 2026', { format: 'Do MMMM YYYY', locale: 'de' }).toString();
// '2026-11-06'
date('2026年11月6日', { format: 'YYYY[年]M[月]Do', locale: 'ja' }).toString();
// '2026-11-06'
yearMonth('février 2026', { format: 'MMMM YYYY', locale: 'fr' }).toString();
// '2026-02'
time('9:05:12.5 pm', { format: 'h:mm:ss.S a', locale: 'en-US' }).toString();
// '21:05:12.500'
```

Английские порядковые токены проверяют точный суффикс, поэтому строка `'24st'` отклоняется, а пользовательские [названия дней недели](/api/configure/) из настроек приложения применяются автоматически.

## Недели ISO и порядковые даты

Шаблоны с порядковым днём года и неделей ISO напрямую преобразуются в календарные даты или моменты времени. Рядом с токеном недели `YYYY` читает недельный год ISO, а не календарный год, который выводит `format()`, поэтому `'2026-W01-1'` разбирается как 29 декабря 2025 года.

Високосные годы, а также 52- и 53-недельные годы проверяются строго; если в неделе ISO не указан день недели, выбирается понедельник.

```js
import { date } from 'native-dates';

date('2026-328', { format: 'YYYY-DDDD' }).toString(); // '2026-11-24'
date('2026-W48-2', { format: 'YYYY-[W]WW-E' }).toString(); // '2026-11-24'
date('2026-W48', { format: 'YYYY-[W]WW' }).toString(); // '2026-11-23'
date('2026-W01-1', { format: 'YYYY-[W]WW-E' }).toString(); // '2025-12-29'
```

## Часовые пояса и метки времени

Шаблоны со смещением задают точный момент времени и переводят его в целевой часовой пояс. Токены `z` внутри строки распознают идентификаторы IANA, а при подключённом [`@native-dates/plugins/zones`](/plugins/zones/) — названия городов и аббревиатуры вроде `JST`, но не произвольные метки смещения вроде `GMT+2`.

Часовой пояс из строки сохраняется в результате, если только не передана опция целевого часового пояса для перевода. Если в строке одновременно указаны смещение и название часового пояса, которые противоречат друг другу для этого момента времени, разбор выбрасывает ошибку.

```js
import '@native-dates/plugins/zones';
import { datetime } from 'native-dates';

datetime('24 Nov 2026 15:45 JST', {
  format: 'DD MMM YYYY HH:mm z',
  locale: 'en-US',
}).zone; // 'Asia/Tokyo'

datetime('24 Nov 2026 15:45 JST', {
  format: 'DD MMM YYYY HH:mm z',
  zone: 'UTC',
  locale: 'en-US',
}).toString(); // '2026-11-24T06:45:00.000Z'

datetime('1795542001', { format: 'X', zone: 'UTC' }).toString();
// '2026-11-24T17:40:01.000Z'
datetime('24112026', { format: 'DDMMYYYY', zone: 'America/New_York' }).toString();
// '2026-11-24T05:00:00.000Z'
```

Метки времени эпохи Unix разбираются токенами `X` для целых секунд и `x` для миллисекунд. Передача шаблона только с датой в [фабричную функцию момента времени](/api/datetime-fn/) возвращает начало этого дня в целевом часовом поясе.

## Сочетание с нестрогим режимом

Подключите [`@native-dates/plugins/loose`](/plugins/loose/) вместе с этим плагином, чтобы возвращать `null` вместо выбрасывания ошибки, если входная строка не соответствует формату. При передаче отсутствующих значений, чисел, невозможных дат и отклонённых переходов на летнее или зимнее время фабричные функции возвращают `null`, а уже готовые экземпляры дат и времени проходят без изменений.

```js
import '@native-dates/plugins/loose';
import { date, datetime } from 'native-dates';

date('not-a-date', { format: 'DDMMYYYY', loose: true }); // null
date('30022026', { format: 'DDMMYYYY', loose: true }); // null
datetime('08/03/2026 02:30', {
  format: 'DD/MM/YYYY HH:mm',
  zone: 'America/New_York',
  disambiguation: 'reject',
  loose: true,
}); // null
```

:::note[Некорректные данные возвращают null, а ошибочные шаблоны по-прежнему выбрасывают ошибку]
Нестрогий режим превращает в `null` только неподходящие входные строки. Пустой или неполный шаблон выбрасывает [`unknownFormat`](/api/errors/#units-zones-and-formats), а токен, которого нет у целевого типа, выбрасывает [`unsupportedToken`](/api/errors/#units-zones-and-formats).
:::

## Поддерживаемые токены

Токены соответствуют словарю форматирования; ведущие и замыкающие пробелы отбрасываются автоматически, если сам шаблон не начинается и не заканчивается пробелом.

| Токен | Пример | Что распознаёт |
|---|---|---|
| `YYYY` | `'2026'` | Четырёхзначный календарный год или недельный год ISO в паре с `W` либо `WW`. |
| `YY` | `'26'` | Двузначный год: 69–99 читаются как 1969–1999, а 00–68 — как 2000–2068. |
| `M`, `MM` | `'9'`, `'09'` | Номер месяца от 1 до 12 — без ведущего нуля или с дополнением до двух цифр. |
| `MMM`, `MMMM` | `'Nov'`, `'November'` | Локализованное сокращённое или полное название григорианского месяца, включая склонённые формы. |
| `D`, `DD` | `'6'`, `'06'` | День месяца от 1 до 31 — без ведущего нуля или с дополнением до двух цифр. |
| `Do` | `'24th'`, `'6.'` | День месяца с английским порядковым суффиксом или маркером дня активной локали. |
| `DDD`, `DDDD` | `'1'`, `'328'` | Порядковый день года по ISO от 1 до 366 — без ведущих нулей или с дополнением до трёх цифр. |
| `W`, `WW` | `'5'`, `'48'` | Номер недели года по ISO от 1 до 53 — без ведущего нуля или с дополнением до двух цифр. |
| `E` | `'2'` | День недели по ISO от 1 (понедельник) до 7 (воскресенье). |
| `d` | `'0'` | День недели от 0 (воскресенье) до 6 (суббота). |
| `dd`, `ddd`, `dddd` | `'Tu'`, `'Tue'`, `'Tuesday'` | Локализованное кратчайшее, сокращённое или полное название дня недели. |
| `H`, `HH` | `'9'`, `'09'` | Час в 24-часовом формате от 0 до 23 — без ведущего нуля или с дополнением до двух цифр. |
| `h`, `hh` | `'9'`, `'09'` | Час в 12-часовом формате от 1 до 12 — без ведущего нуля или с дополнением до двух цифр. |
| `m`, `mm` | `'5'`, `'05'` | Минуты от 0 до 59 — без ведущего нуля или с дополнением до двух цифр. |
| `s`, `ss` | `'8'`, `'08'` | Секунды от 0 до 59 — без ведущего нуля или с дополнением до двух цифр. |
| `S`, `SS`, `SSS` | `'5'`, `'25'`, `'250'` | Дробные доли секунды: десятые, сотые или миллисекунды. |
| `A`, `a` | `'PM'`, `'pm'` | `AM` или `PM` в английском без учёта регистра либо обозначение части суток активной локали. |
| `Z`, `ZZ` | `'-05:00'`, `'-0500'` | Смещение UTC с двоеточием или без него, либо `Z` для UTC. |
| `z`, `zz` | `'UTC'`, `'JST'` | Идентификатор часового пояса IANA без пробелов, а при подключённом `@native-dates/plugins/zones` — город или аббревиатура. Не разбирает метки смещения вроде `'GMT+2'`. |
| `X`, `x` | `'1795542001'` | Метка времени эпохи Unix в целых секундах или миллисекундах, включая отрицательные значения. |
| `[text]` | `'[W]'` | Экранированный литеральный текст, сверяемый с учётом регистра. Одиночная буква `T` тоже проходит без экранирования. |

Токены, предназначенные только для форматирования (например, кварталы и полные названия часовых поясов), не разбираются и выбрасывают [`unknownFormat`](/api/errors/#units-zones-and-formats). Шаблоны без обязательных полей для целевого типа выбрасывают ту же ошибку, а токены, которых нет у целевого типа, выбрасывают [`unsupportedToken`](/api/errors/#units-zones-and-formats).

## Опции фабричных функций

:::entry
### `datetime()` :kind[function]

```js signature
datetime(input, { format, zone?, locale?, disambiguation?, loose? }): DateTime
date(input, { format, locale?, loose? }): CalendarDate
time(input, { format, locale?, loose? }): Time
yearMonth(input, { format, locale?, loose? }): YearMonth
monthYear(input, { format, locale?, loose? }): YearMonth
monthDay(input, { format, locale?, loose? }): MonthDay
dayMonth(input, { format, locale?, loose? }): MonthDay
dateRange(start, end, { format, locale?, loose? }): DateRange
datetimeRange(start, end, { format, zone?, locale?, disambiguation?, loose? }): DateTimeRange
timeRange(start, end, { format, locale?, loose? }): TimeRange
```

Разбирает строковый ввод по шаблону токенов или именованному формату во всех фабричных функциях дат, времени суток, частичных дат и диапазонов. Уже разобранные значения дат и времени, объекты `Date` и `Temporal` проходят без изменений после проверки шаблона, а числа отклоняются.

**Параметры**

```params
- name: format
  type: string
  required: true
  description: "Шаблон токенов вроде `'DDMMYYYY'` или именованный шаблон, зарегистрированный в `configure({ formats })`."
- name: zone
  type: Zone
  description: Часовой пояс для интерпретации локальных строк даты и времени либо перевода меток со смещением и меток эпохи Unix.
- name: locale
  type: Locale
  description: Тег локали BCP 47, сохраняемый в значении и используемый для названий месяцев, дней недели, частей суток и порядковых чисел.
- name: disambiguation
  type: Disambiguation
  default: "'compatible'"
  description: "Способ разрешения неоднозначности при переходе на летнее или зимнее время для локальных строк даты и времени. Значение `'reject'` выбрасывает `invalidDateTime` или возвращает `null` в нестрогом режиме."
- name: loose
  type: boolean
  default: "false"
  description: "Возврат `null` вместо выбрасывания ошибки, если входная строка не соответствует формату (требует `@native-dates/plugins/loose`)."
```

**Возвращаемое значение**

```returns
type: DateTime | CalendarDate | Time | YearMonth | MonthDay | Range
description: "Разобранный экземпляр или `null`, если в фабричной функции задано `{ loose: true }`, а входная строка не соответствует формату."
```

```js
date('24112026', { format: 'DDMMYYYY' }).toString(); // '2026-11-24'
yearMonth('202611', { format: 'YYYYMM' }).toString(); // '2026-11'
timeRange('0930', '1700', { format: 'HHmm' }).toString(); // '09:30:00/17:00:00'
```
:::
