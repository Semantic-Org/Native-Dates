## Структура ошибки

Некорректные вызовы завершаются ошибкой сразу, а не возвращают сломанные объекты дат или `NaN`, которые незаметно ломают дальнейшие вычисления. Каждое выброшенное исключение — это стандартная ошибка JavaScript с двумя дополнительными свойствами:

- **`error.code`** содержит стабильный идентификатор в стиле camelCase, например `'invalidDate'` или `'unknownZone'`.
- **`error.at`** повторяет проблемное входное значение или цель операции в виде строки, например `'2026-02-30'`.

Неподходящие типы аргументов и несовместимые виды значений выбрасывают `TypeError`. Невозможные даты, нечитаемые строки, неизвестные единицы или часовые пояса и неподдерживаемые операции выбрасывают `RangeError`.

```js title="catch.js"
import { date } from 'native-dates';

try {
  date('2026-02-30');
} catch (error) {
  error instanceof RangeError; // true
  error.code; // 'invalidDate'
  error.at; // '2026-02-30'
}
```

В режиме разработки `error.message` содержит вторую строку на английском языке с объяснением, как исправить вызов. Продакшн-сборки при `NODE_ENV === 'production'` автоматически вырезают эти пояснения, оставляя код ошибки и проблемное значение без изменений.

## Обработка недоверенного ввода

Проверяйте `error.code`, когда нужны собственные сообщения валидации для конкретных ошибок, и пробрасывайте неожиданные исключения дальше:

```js
import { datetime } from 'native-dates';

function parseTimestamp(raw, zone) {
  try {
    return datetime(raw, zone);
  } catch (error) {
    if (error.code === 'invalidDateTime') {
      return null;
    }
    throw error;
  }
}

parseTimestamp('not-a-date', 'UTC'); // null
```

При разборе пользовательских полей форм, параметров запроса или ячеек CSV, где нечитаемый текст должен давать `null`, импортируйте [`@native-dates/plugins/loose`](/plugins/loose/) и включите нестрогий режим:

```js
import { date, duration } from 'native-dates';
import '@native-dates/plugins/loose';

date('2026-02-30', { loose: true }); // null
duration('whenever', { loose: true }); // null
```

:::tip[Ошибки данных и ошибки кода в нестрогом режиме]
Нестрогий режим возвращает `null` только тогда, когда само входное значение не удаётся разобрать. Ошибки в опциях вашего вызова — например, неизвестный часовой пояс или перепутанные границы диапазона — по-прежнему выбрасывают исключение, чтобы баги не оставались незамеченными.
:::

## Коды TypeError

Ошибки типа сообщают, что обязательный аргумент отсутствует, имеет неверный тип JavaScript или относится к другому понятию времени, чем ожидалось.

| Код | Источник | Причина |
|---|---|---|
| `missingDateTime` | `datetime()`, `DateTime` | Входное значение равно `null` или `undefined`. |
| `missingDate` | `date()`, `CalendarDate` | Входное значение равно `null` или `undefined`. |
| `missingTime` | `time()`, `Time` | Входное значение равно `null` или `undefined`. |
| `missingYearMonth` | `yearMonth()`, `monthYear()`, `YearMonth` | Входное значение равно `null` или `undefined`. |
| `missingMonthDay` | `monthDay()`, `dayMonth()`, `MonthDay` | Входное значение равно `null` или `undefined`. |
| `invalidDateTime` | `datetime()`, `DateTime` | Входное значение имеет неподдерживаемый тип, например булево значение. |
| `invalidDate` | `date()`, `CalendarDate` | Передано одно число без остальных аргументов или неподдерживаемый тип. |
| `invalidTime` | `time()`, `Time` | Входное значение имеет неподдерживаемый тип. |
| `invalidYearMonth` | `yearMonth()`, `monthYear()`, `YearMonth` | Передано одно число или неподдерживаемый тип. |
| `invalidMonthDay` | `monthDay()`, `dayMonth()`, `MonthDay` | Передано одно число или неподдерживаемый тип. |
| `invalidDuration` | `duration()`, `Duration`, `plus()`, `minus()` | Входное значение равно `null` или `undefined`, имеет неподдерживаемый тип, либо единица передана вместе с длительностью, у которой уже есть единицы. |
| `unsupportedCalendar` | `yearMonth()`, `monthDay()`, `YearMonth`, `MonthDay` | Передан `Temporal.PlainYearMonth` или `PlainMonthDay` с не-ISO календарём. |
| `invalidPoint` | `compare()`, `earliest()`, `latest()` | Значение не относится к `DateTime`, `CalendarDate`, `Time`, `YearMonth`, `Date`, временным меткам эпохи Unix, точкам Temporal или разбираемым строкам. |
| `conflictingKinds` | `compare()`, `earliest()`, `latest()` | Сравнение значений разных видов, например `CalendarDate` с `DateTime`. |
| `invalidRange` | `mergeRanges()` | Передача неитерируемого значения или элемента, не относящегося к диапазонам, при подключённом [`@native-dates/plugins/ranges`](/plugins/ranges/). |
| `conflictingRanges` | `DateRange`, `DateTimeRange`, `TimeRange`, `subtract()`, `union()`, `mergeRanges()` | Передача диапазона одного вида в конструктор класса, фабричную функцию или операцию над множествами для другого диапазона. |

## Коды RangeError

Ошибки диапазона сообщают, что значение невозможно разобрать, оно выходит за допустимые границы либо запрашивает неподдерживаемую единицу, часовой пояс или операцию.

### Разбор и значения

| Код | Источник | Причина |
|---|---|---|
| `invalidDateTime` | `datetime()`, `DateTime` | Строку не удалось разобрать как дату и время, либо поля содержат недопустимые значения вроде 30 февраля. |
| `invalidDate` | `date()`, `CalendarDate` | Строку не удалось разобрать как дату, переданы дробные числа или поля выходят за допустимые границы. |
| `missingDay` | `date()`, `CalendarDate` | В числовом вызове `(year, month)` пропущен аргумент `day`. |
| `invalidTime` | `time()`, `Time` | Строку не удалось разобрать как время суток, 12-часовое значение вне диапазона 1–12 или поля времени выходят за допустимые границы. |
| `invalidYearMonth` | `yearMonth()`, `monthYear()`, `YearMonth` | Строку не удалось разобрать как год и месяц, переданы дробные числа или месяц вне диапазона 1–12. |
| `invalidMonthDay` | `monthDay()`, `dayMonth()`, `MonthDay` | Строку не удалось разобрать как месяц и день, в `equals()` передана строка с неоднозначным разделителем или поля выходят за допустимые границы. |
| `invalidYear` | `MonthDay.in()` | В `in()` передан нецелый год или год вне поддерживаемого диапазона Temporal. |
| `invalidDay` | `YearMonth.on()` | Переданный в `on()` день — не целое число от 1 до 31. |
| `invalidDuration` | `duration()`, `Duration` | Пустая или неразбираемая английская фраза длительности, некорректная строка ISO 8601 или поля длительности вне допустимых границ. |
| `invalidNumber` | `datetime()`, `duration()`, функции единиц | Числовой аргумент равен `NaN`, `Infinity`, `-Infinity`, либо передан некорректный экземпляр `Date`. |
| `conflictingSigns` | `duration()`, `Duration`, `minus()` | Длительность смешивает положительные и отрицательные единицы без возможности корректного заимствования, например `'1h -30m'` или непривязанные дни минус часы. |
| `invalidFraction` | `duration()`, `months()`, `times()` | Дробные месяцы или наносекунды нельзя перевести в меньшую фиксированную единицу. |

### Единицы, часовые пояса и форматы

| Код | Источник | Причина |
|---|---|---|
| `unknownUnit` | Арифметика, границы, округление, `set()`, `duration()` | Нераспознанное английское название единицы или сокращение. |
| `unknownDayOfWeek` | `dayOfWeek()`, `next()`, `previous()`, границы недели, `configure()` | Нераспознанное английское название дня недели или число дня недели вне диапазона 1–7. |
| `unknownSetting` | `configure()` | Нераспознанный ключ настройки в `configure()`. |
| `unknownWidth` | `configure()` | Запись в `weekdayNames` указывает ширину, отличную от `narrow`, `short` и `long`, либо не задаёт ширину. |
| `unknownZone` | Фабричные функции, `in()`, `configure()` | Неизвестный идентификатор часового пояса IANA, нестроковый пояс или некорректное смещение UTC. |
| `invalidZoneAliases` | `configure()` | Значение `zoneAliases` — не простой объект и не `null`. |
| `unknownLocale` | `locale()`, фабричные функции, `format()`, `monthNames()`, `weekdayNames()`, `configure()` | Тег локали, список тегов или заголовок `Accept-Language` содержит некорректный тег локали. |
| `unknownFormat` | `format()`, `monthNames()`, `weekdayNames()` | Некорректная спецификация формата или опции `Intl`, неподдерживаемый стиль длительности или подписи либо нераспознанные или склеенные токены вне `[квадратных скобок]`. |
| `unsupportedToken` | `format()` | Шаблон токенов запрашивает поле, которого нет у значения, — например, `HH` у `CalendarDate` или `YYYY` у `Time`. |
| `unknownKind` | `as()`, `DateRange.count()` | Целевой вид не поддерживается получателем. |

### Арифметика и измерения

| Код | Источник | Причина |
|---|---|---|
| `unsupportedUnit` | `CalendarDate`, `Time`, `YearMonth` | Использование единиц времени суток на `CalendarDate`, календарных единиц на `Time` или единиц меньше месяца на `YearMonth`. |
| `cannotAdd` | `plus()`, `add()` | Сложение выходит за пределы представимого диапазона дат Temporal. |
| `cannotSubtract` | `minus()`, `subtract()` | Вычитание выходит за пределы представимого диапазона дат Temporal. |
| `cannotSet` | `set()` | Значение поля дробное или выходит за допустимые границы для этого календарного месяца или единицы времени суток. |
| `cannotRound` | `round()`, `floor()`, `ceil()`, `Time.startOf()`, `Time.startOfNext()`, `Time.startOfPrevious()` | Неподдерживаемая единица округления или шаг, на который следующая единица не делится нацело. |
| `missingAnchor` | `Duration.balance()`, `total()`, `compare()` | Непривязанной длительности нужна начальная календарная дата, чтобы перевести месяцы или годы в недели, дни или единицы времени суток. |
| `cannotBalance` | `Duration.balance()` | Балансировка длительности приводит к переполнению или ошибке округления в Temporal. |
| `cannotTotal` | `Duration.total()`, `until()`, `since()` | Подсчёт суммарной длительности приводит к переполнению или использует неподдерживаемую единицу. |
| `missingPoints` | `earliest()`, `latest()` | Вызов без аргументов или с пустым массивом. |
| `unsupportedComparison` | `CalendarDate`, `Time`, `YearMonth`, `MonthDay`, диапазоны | Числовое приведение через `valueOf()`, унарный `+`, `-`, `<` или `>` для типа без числовой метки эпохи Unix. |

### Диапазоны

| Код | Источник | Причина |
|---|---|---|
| `invalidRange` | `DateRange`, `DateTimeRange`, `to()` | Конечная граница `end` раньше начальной `start`. |
| `invalidStep` | `every()`, `split()` | Длительность шага, переданная в `every()` или `split()`, равна нулю или отрицательна. |
| `unsupportedIntersection` | `TimeRange.intersection()` | Два диапазона времени суток, переходящие через полночь, пересекаются в двух отдельных промежутках. |
| `unsupportedUnion` | `TimeRange.union()`, `mergeRanges()` | Диапазоны времени суток покрывают все 24 часа, что нельзя представить одним `TimeRange`. |
| `unsupportedZone` | `TimeRange.in()` | Вызов `in()` на `TimeRange`, у которого нет календарной даты для привязки к часовому поясу. |

### Плагины

| Код | Источник | Причина |
|---|---|---|
| `missingPlugin` | Фабричные функции, `configure()` | Использование `loose`, `dayFirst`, `format` или `zoneAliases` до импорта соответствующего плагина. |
| `missingTemporal` | Фабричные функции, конструкторы, `configure({ zone })` | Диагностическое пояснение только для режима разработки, если `globalThis.Temporal` отсутствует, а `@native-dates/polyfill` не подключён (в продакшн-сборке эта проверка вырезается, и среда выполнения выбрасывает нативный `ReferenceError`). |
| `immutable` | Устаревшие сеттеры `DateTime` | Вызов мутирующего сеттера `Date` (например, `setHours()`) при подключённом [`@native-dates/plugins/legacy-date`](/plugins/legacy-date/). |
