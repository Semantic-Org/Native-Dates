Чтобы форматировать даты по-русски, передайте тег `'ru'` любым способом из руководства [Локализация](/guides/localization/). Встроенный `Intl` автоматически подбирает падежи месяцев и формы числительных — отдельные файлы локалей не требуются.

## Падежи месяцев и суффикс «г.»

Пресеты Native Dates автоматически ставят месяц в родительный падеж рядом с числом, оставляют именительный для самостоятельного `YearMonth` и добавляют «г.» после года:

```js
import { date, yearMonth } from 'native-dates';

const release = date('2026-11-16').locale('ru');

release.format('long'); // '16 ноября 2026 г.'
release.format('medium'); // '16 нояб. 2026 г.'
yearMonth('2026-11').format('long', 'ru'); // 'ноябрь 2026 г.'
```

В шаблонах токенов суффикс «г.» опускается, что удобно для компактных подписей в интерфейсе. Токены `MMMM` и `MMM` сами переключаются с именительного падежа на родительный, если перед ними стоит токен дня:

```js
const may = date('2026-05-06').locale('ru');

may.format('MMMM YYYY'); // 'май 2026'
may.format('D MMMM YYYY'); // '6 мая 2026'
may.format('D MMM'); // '6 мая'
date('2026-03-08').format('D MMM', 'ru'); // '8 мар.'
```

Буквенные наращения вроде `-го` между днём и месяцем сохраняют родительный падеж у `MMMM` как в квадратных скобках, так и без них:

```js
may.format('D-го MMMM'); // '6-го мая'
```

## Дни недели, регистр и порядковые числа

В русской локали `weekStart` равен `1` (неделя начинается с понедельника), а названия месяцев и дней недели выводятся со строчной буквы.

Оба стиля — `narrow` и `short` — возвращают двухбуквенные сокращения `пн`–`вс` вместо неоднозначных однобуквенных:

```js
import { date, weekdayNames } from 'native-dates';

weekdayNames('narrow', undefined, 'ru');
// ['пн', 'вт', 'ср', 'чт', 'пт', 'сб', 'вс']
date('2026-11-16').format('dddd, D MMMM', 'ru'); // 'понедельник, 16 ноября'
```

Токен `Do` по умолчанию выводит просто число без точки и наращений. Если в интерфейсе нужны наращения вроде `16-е` или сокращения дней недели с заглавной буквы, задайте их в [`configure()`](/api/configure/):

```js
import { configure, date } from 'native-dates';

configure({
  weekdayNames: { ru: { short: { mon: 'Пн', fri: 'Пт' } } },
  ordinals: { ru: (day) => `${day}-е` },
});

date('2026-11-16').format('ddd, Do MMMM', 'ru'); // 'Пн, 16-е ноября'
```

## Склонение длительностей и относительные даты

Форматирование [`Duration`](/api/duration/) опирается на встроенные правила множественного числа `Intl`, поэтому склонение числительных работает автоматически без ручных словарей и таблиц окончаний:

```js
import { days, duration } from 'native-dates';

days(1).format('long', 'ru'); // '1 день'
days(2).format('long', 'ru'); // '2 дня'
days(5).format('long', 'ru'); // '5 дней'
days(21).format('long', 'ru'); // '21 день'
duration({ days: 2, hours: 5, minutes: 21 }).format('long', 'ru');
// '2 дня 5 часов 21 минута'
```

У [`DateTime`](/api/date-time/) метод [`from()`](/api/date-time/#from) отсчитывает прошедшие часы и минуты, поэтому событие за 22 часа до полуночи остаётся числовой фразой и не превращается во «вчера».

У [`CalendarDate`](/api/calendar-date/) сравнение идёт по календарным дням, и `from()` возвращает готовые относительные обозначения вплоть до *позавчера* и *послезавтра*:

```js
import { date, datetime } from 'native-dates';

const day = date('2026-11-16').locale('ru');
day.minus(2, 'days').from(day); // 'позавчера'
day.minus(1, 'day').from(day); // 'вчера'
day.plus(2, 'days').from(day); // 'послезавтра'

const moment = datetime('2026-11-16T12:00:00Z', 'Europe/Moscow').locale('ru');
moment.minus(1, 'minute').from(moment); // '1 минуту назад'
moment.plus(2, 'days').from(moment); // 'через 2 дня'
```

## Разбор дат через точку и русских месяцев

Ядро напрямую разбирает строки с годом в начале вроде `'2026.11.16'`. С [плагином loose](/plugins/loose/) русская локаль автоматически распознаёт даты через точку с днём в начале, названия месяцев в именительном и родительном падежах и суффикс «г.» после года:

```js
import '@native-dates/plugins/loose';
import { date, datetime } from 'native-dates';

date('16.11.2026', { loose: true, locale: 'ru' })?.toString(); // '2026-11-16'
date('06.11.2026', { loose: true, locale: 'ru' })?.toString(); // '2026-11-06'
date('16 ноября 2026 г.', { loose: true, locale: 'ru' })?.toString(); // '2026-11-16'
datetime('16.11.2026, 14:30', {
  zone: 'Europe/Moscow',
  locale: 'ru',
  loose: true,
})?.hour; // 14
```

Частичные числовые даты через точку ядро разбирает без плагинов, а нестрогий режим поддерживает и русские названия месяцев в обоих падежах:

```js
import { dayMonth, monthDay, monthYear, yearMonth } from 'native-dates';

dayMonth('06.11').toString(); // '11-06'
monthYear('11.2026').toString(); // '2026-11'
monthDay('16 ноября', { loose: true, locale: 'ru' })?.toString(); // '11-16'
yearMonth('ноябрь 2026 г.', { loose: true, locale: 'ru' })?.toString(); // '2026-11'
```

## Часовые пояса России и соседних стран

Россия охватывает одиннадцать часовых поясов без сезонного перевода часов, а Казахстан в 2024 году перешёл на единый часовой пояс UTC+5. Полные идентификаторы IANA сохраняют историю всех изменений смещений в каждом поясе.

С [плагином zones](/plugins/zones/) английские названия городов из базы IANA, крупные российские и казахстанские города на латинице, кириллические названия и сокращения вроде `'москва'`, `'мск'` и `'MSK'` распознаются напрямую без настройки собственных псевдонимов:

| Запрос | Статус по умолчанию | Обработка |
|---|---|---|
| `'Europe/Moscow'`, `'Asia/Almaty'` | Работает в ядре | Полные идентификаторы IANA доступны из коробки и хранят историю смещений. |
| `'Moscow'`, `'Yekaterinburg'`, `'Minsk'` | Работает с плагином | Английские названия городов из идентификаторов IANA распознаются без учёта регистра. |
| `'MSK'`, `'мск'`, `'SPB'`, `'Kazan'`, `'Astana'` | Работает с плагином | Встроенные региональные сокращения, варианты написания и кириллические названия определяются напрямую. |

```js
import '@native-dates/plugins/loose';
import '@native-dates/plugins/zones';
import { datetime } from 'native-dates';

datetime('2026-11-16T12:00:00Z', 'MSK').format('HH:mm', 'ru'); // '15:00'
datetime('2026-11-16T12:00:00Z', 'мск').zone; // 'Europe/Moscow'
datetime('2026-11-16T12:00:00Z', 'SPB').zone; // 'Europe/Moscow'
datetime('2026-11-16T12:00:00Z', 'Astana').offset; // '+05:00'
datetime('16 ноября 2026 14:30 мск', {
  loose: true,
  locale: 'ru',
  zone: 'UTC',
})?.toString(); // '2026-11-16T11:30:00.000Z'
```
