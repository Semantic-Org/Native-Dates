Передайте `'ru'` через [Локализацию](/guides/localization/), чтобы форматировать даты по-русски. Встроенные данные `Intl` сами склоняют месяцы по падежам и выбирают формы множественного числа без внешних словарей.

## Падежи месяцев и подпись «г.»

Готовые пресеты ставят месяц рядом с числом в родительный падеж, оставляют именительный без дня и добавляют после года «г.»:

```js
import { date, yearMonth } from 'native-dates';

const release = date('2026-11-16').locale('ru');

release.format('long'); // '16 ноября 2026 г.'
release.format('medium'); // '16 нояб. 2026 г.'
yearMonth('2026-11').format('long', 'ru'); // 'ноябрь 2026 г.'
```

Шаблоны токенов опускают «г.» в компактных подписях и переключают `MMMM` и `MMM` с именительного *май* на родительный *мая* сразу после токена дня:

```js
const may = date('2026-05-06').locale('ru');

may.format('MMMM YYYY'); // 'май 2026'
may.format('D MMMM YYYY'); // '6 мая 2026'
may.format('D MMM'); // '6 мая'
date('2026-03-08').format('D MMM', 'ru'); // '8 мар.'
```

Буквенные наращения вроде `-го` между числом и месяцем сохраняют родительный падеж у `MMMM` как в квадратных скобках, так и без них:

```js
may.format('D-го MMMM'); // '6-го мая'
```

## Дни недели, строчные буквы и числа месяца

Названия месяцев и дней недели по-русски пишутся со строчной буквы, а неделя начинается с понедельника при `weekStart` равном `1`.

Однобуквенные сокращения совпадают сразу у нескольких дней недели, поэтому узкий и короткий стили возвращают двухбуквенные *пн*–*вс* с понедельника по воскресенье:

```js
import { date, weekdayNames } from 'native-dates';

weekdayNames('narrow', undefined, 'ru');
// ['пн', 'вт', 'ср', 'чт', 'пт', 'сб', 'вс']
date('2026-11-16').format('dddd, D MMMM', 'ru'); // 'понедельник, 16 ноября'
```

Точка после числа месяца в русском языке не ставится, поэтому `Do` выводит само число, если не задать наращения и заглавные дни недели в [`configure()`](/api/configure/):

```js
import { configure, date } from 'native-dates';

configure({
  weekdayNames: { ru: { short: { mon: 'Пн', fri: 'Пт' } } },
  ordinals: { ru: (day) => `${day}-е` },
});

date('2026-11-16').format('ddd, Do MMMM', 'ru'); // 'Пн, 16-е ноября'
```

## Склонение длительностей и относительные даты

Русские числительные выбирают одну из трёх форм для 1 и 21, от 2 до 4 и от 5 до 20. Форматирование `Duration` подставляет нужную форму автоматически:

```js
import { days, duration } from 'native-dates';

days(1).format('long', 'ru'); // '1 день'
days(2).format('long', 'ru'); // '2 дня'
days(5).format('long', 'ru'); // '5 дней'
days(21).format('long', 'ru'); // '21 день'
duration({ days: 2, hours: 5, minutes: 21 }).format('long', 'ru');
// '2 дня 5 часов 21 минута'
```

У `DateTime` метод `from()` считает прошедшие часы и минуты, чтобы за 22 часа до полуночи дата не превращалась во «вчера».

У `CalendarDate` метод сравнивает календарные дни и возвращает русские наречия времени вплоть до *позавчера* и *послезавтра*:

```js
import { date, datetime } from 'native-dates';

const day = date('2026-11-16').locale('ru');
day.minus(2, 'days').from(day); // 'позавчера'
day.minus(1, 'day').from(day); // 'вчера'
day.plus(2, 'days').from(day); // 'послезавтра'

const moment = datetime('2026-11-16T12:00:00Z', 'Europe/Moscow').locale('ru');
moment.minus(1, 'minute').from(moment); // '1 минуту назад'
moment.plus(2, 'days').from(moment); // 'через 2 дня'
```

## Разбор дат через точку и русских месяцев

Ядро принимает строки с годом в начале вроде `'2026.11.16'`. С [нестрогим плагином](/plugins/loose/) параметр `locale: 'ru'` автоматически читает даты через точку с днём впереди, склоняемые названия месяцев и подпись *г.* после года без включения `dayFirst`:

```js
import '@native-dates/plugins/loose';
import { date, datetime } from 'native-dates';

date('16.11.2026', { loose: true, locale: 'ru' })?.toString(); // '2026-11-16'
date('06.11.2026', { loose: true, locale: 'ru' })?.toString(); // '2026-11-06'
date('16 ноября 2026 г.', { loose: true, locale: 'ru' })?.toString(); // '2026-11-16'
datetime('16.11.2026, 14:30', {
  zone: 'Europe/Moscow',
  locale: 'ru',
  loose: true,
})?.hour; // 14
```

Частичные числовые даты через точку читаются в ядре напрямую, а нестрогий режим распознаёт именительный и родительный падежи русских месяцев:

```js
import { dayMonth, monthDay, monthYear, yearMonth } from 'native-dates';

dayMonth('06.11').toString(); // '11-06'
monthYear('11.2026').toString(); // '2026-11'
monthDay('16 ноября', { loose: true, locale: 'ru' })?.toString(); // '11-16'
yearMonth('ноябрь 2026 г.', { loose: true, locale: 'ru' })?.toString(); // '2026-11'
```

## Часовые пояса России и соседних стран

Россия охватывает одиннадцать часовых зон без сезонного перевода стрелок, а Казахстан в 2024 году перешёл на единый пояс UTC+5. Полные идентификаторы IANA сохраняют историю смещений в каждой зоне.

С [плагином часовых поясов](/plugins/zones/) города из базы IANA, `'MSK'`, `'мск'`, `'Москва'`, Санкт-Петербург, `'SPB'`, Казань, Екатеринбург и Астана определяются напрямую без псевдонимов:

| Запрос | Статус по умолчанию | Обработка |
|---|---|---|
| `'Europe/Moscow'`, `'Asia/Almaty'` | Работает в ядре | Полные идентификаторы IANA доступны сразу и хранят историю переходов. |
| `'Moscow'`, `'Yekaterinburg'`, `'Minsk'` | Работает с плагином | Города из идентификаторов IANA сопоставляются без учёта регистра. |
| `'MSK'`, `'мск'`, `'SPB'`, `'Kazan'`, `'Astana'` | Работает с плагином | Встроенные региональные сокращения, варианты написания и кириллические названия определяются напрямую. |

```js
import '@native-dates/plugins/loose';
import '@native-dates/plugins/zones';
import { datetime } from 'native-dates';

datetime('2026-11-16T12:00:00Z', 'MSK').format('HH:mm', 'ru'); // '15:00'
datetime('2026-11-16T12:00:00Z', 'мск').zone; // 'Europe/Moscow'
datetime('2026-11-16T12:00:00Z', 'SPB').zone; // 'Europe/Moscow'
datetime('2026-11-16T12:00:00Z', 'Astana').offset; // '+05:00'
datetime('16 ноября 2026 14:30 мск', {
  loose: true,
  locale: 'ru',
  zone: 'UTC',
})?.toString(); // '2026-11-16T11:30:00.000Z'
```
