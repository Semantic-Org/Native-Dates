Вместо базового тега `'ar'` передавайте тег с указанием страны, например `'ar-EG'` или `'ar-SA'`, любым способом из руководства [Локализация](/guides/localization/). Начертание цифр, названия григорианских месяцев и первый день недели различаются от страны к стране.

## Восточноарабские и западные цифры

ОАЭ, страны Магриба и базовый тег `'ar'` выводят западные цифры, а Египет, Саудовская Аравия, страны Леванта и Ирак — восточноарабские.

Чтобы зафиксировать одну систему цифр для всех пользователей, добавьте к тегу локали `-u-nu-latn` или `-u-nu-arab`:

```js
import { date } from 'native-dates';

const invoice = date('2026-11-16');

invoice.format('long', 'ar-EG'); // '١٦ نوفمبر ٢٠٢٦'
invoice.format('long', 'ar-AE'); // '16 نوفمبر 2026'
invoice.format('long', 'ar-EG-u-nu-latn'); // '16 نوفمبر 2026'
invoice.format('long', 'ar-MA-u-nu-arab'); // '١٦ نونبر ٢٠٢٦'
```

Шаблоны токенов всегда выводят цифры ASCII, локализуя только названия месяцев и дней недели. Числовые пресеты вставляют перед косой чертой маркеры направления справа налево `\u200F`, поэтому для проверок в тестах, CSV и URL надёжнее использовать `'YYYY-MM-DD'`:

```js
invoice.format('YYYY-MM-DD', 'ar-EG'); // '2026-11-16'
invoice.format('dddd، D MMMM YYYY', 'ar-SA'); // 'الاثنين، 16 نوفمبر 2026'
invoice.format('short', 'ar-EG'); // '١٦\u200F/١١\u200F/٢٠٢٦'
```

## Календарь Хиджры и региональные названия месяцев

Современные движки по умолчанию используют для `'ar-SA'` григорианский календарь. Чтобы форматировать официальные даты по календарю Хиджры Умм аль-Кура (например, 1 шавваля 1447 года Хиджры), добавьте расширение `'-u-ca-islamic-umalqura'` к тегу локали при вызове пресета:

```js
import { date } from 'native-dates';

const eid = date('2026-03-20');

eid.format('long', 'ar-SA'); // '٢٠ مارس ٢٠٢٦'
eid.format('long', 'ar-SA-u-ca-islamic-umalqura'); // '١ شوال ١٤٤٧ هـ'
eid.format('D MMMM YYYY', 'ar-SA-u-ca-islamic-umalqura'); // '20 مارس 2026'
```

Шаблоны токенов и частичные даты остаются в григорианском календаре, поскольку один солнечный месяц охватывает два месяца Хиджры. Сначала привяжите конкретный день методом [`on()`](/api/year-month/#on):

```js
import { yearMonth } from 'native-dates';

const march = yearMonth('2026-03');

march.format('long', 'ar-SA-u-ca-islamic-umalqura'); // 'مارس ٢٠٢٦'
march.on(1).format('long', 'ar-SA-u-ca-islamic-umalqura'); // '١٢ رمضان ١٤٤٧ هـ'
march.on(20).format('long', 'ar-SA-u-ca-islamic-umalqura'); // '١ شوال ١٤٤٧ هـ'
```

Названия григорианских месяцев и выбор между 12- и 24-часовым форматом делятся на четыре региональные группы:

| Регион | Примеры тегов | Особенности вывода |
|---|---|---|
| Египет, страны Залива, Судан | `ar-EG, ar-SA` | Названия месяцев, принятые в Египте и странах Персидского залива (يناير, يوليو, نوفمبر), и 12-часовой формат с `ص` / `م` для AM и PM. |
| Левант и Ирак | `ar-LB, ar-IQ` | Левантийские названия месяцев (كانون الثاني, تموز, تشرين الثاني) и 12-часовой формат. |
| Марокко | `ar-MA` | Марокканские названия месяцев (ماي, يوليوز, غشت, شتنبر, نونبر, دجنبر) и 24-часовой формат. |
| Алжир и Тунис | `ar-DZ, ar-TN` | Названия месяцев стран Магриба (جانفي, فيفري, جوان, جويلية, أوت) и 12-часовой формат. |

```js
import { datetime } from 'native-dates';

const july = datetime('2026-07-16T14:30', 'UTC');

july.format('long', 'ar-EG'); // '١٦ يوليو ٢٠٢٦ في ٢:٣٠ م'
july.format('long', 'ar-LB'); // '١٦ تموز ٢٠٢٦ في ٢:٣٠ م'
july.format('long', 'ar-MA'); // '16 يوليوز 2026 في 14:30'
july.format('long', 'ar-DZ'); // '16 جويلية 2026 في 2:30 م'
```

## Начало недели и выходные

В Египте, Иордании, Катаре и Алжире неделя начинается в субботу, в Саудовской Аравии и Йемене — в воскресенье, а в ОАЭ, Марокко, Тунисе и Ливане — в понедельник.

Свойство `weekStart`, границы недель и заголовки дней недели подстраиваются под каждый тег автоматически. Для сводных отчётов по разным странам можно явно передать английское название дня недели `'monday'`:

```js
import { date, weekdayNames } from 'native-dates';

const wed = date('2026-11-18');

wed.locale('ar-EG').startOf('week').toString(); // '2026-11-14'
wed.locale('ar-SA').startOf('week').toString(); // '2026-11-15'
wed.locale('ar-AE').startOf('week').toString(); // '2026-11-16'
weekdayNames('narrow', undefined, 'ar-EG')[0]; // 'س'
```

Методы [`isWeekend()`](/api/calendar-date/#calendar-predicates) и [`isWeekday()`](/api/calendar-date/#calendar-predicates) тоже следуют активной локали. В странах с выходными в пятницу и субботу (таких как Саудовская Аравия и Египет) пятница считается выходным, а воскресенье — рабочим днём:

```js
const fri = date('2026-11-20').locale('ar-SA');
const sun = date('2026-11-22').locale('ar-SA');

fri.isWeekend(); // true
sun.isWeekend(); // false
sun.isWeekday(); // true
```

## Шесть форм множественного числа и текст справа налево

В арабском языке шесть форм множественного числа: для нуля, единицы, двойственного числа (например, *يومان*), чисел 3–10, 11–99 и сотен. [`Duration`](/api/duration/) и [`from()`](/api/date-time/#from) выбирают нужную форму автоматически, а для календарных дат возвращают относительные обозначения дней вплоть до *بعد الغد* («послезавтра»):

```js
import { datetime, days } from 'native-dates';

days(1).format('long', 'ar-EG'); // 'يوم'
days(2).format('long', 'ar-EG'); // 'يومان'
days(5).format('long', 'ar-EG'); // '٥ أيام'
days(15).format('long', 'ar-EG'); // '١٥ يومًا'
days(100).format('long', 'ar-EG'); // '١٠٠ يوم'

const anchor = datetime('2026-11-16T09:00', 'Asia/Riyadh');
anchor.plus(2, 'days').from(anchor, 'ar-SA'); // 'خلال يومين'
anchor.date.plus(2, 'days').from(anchor.date, 'ar-SA'); // 'بعد الغد'
```

Внутри абзацев с письмом справа налево браузеры могут переставлять знаки в датах ISO и смещениях UTC, поэтому оборачивайте технические метки в `<bdi>`:

```html
<p dir="rtl">
  موعد الصيانة: ١٠–١٦ نوفمبر ٢٠٢٦ عند الساعة <bdi>09:00 +03:00</bdi>
</p>
```

## Разбор ввода и часовые пояса

С [плагином loose](/plugins/loose/) арабские локали автоматически разбирают даты через косую черту с днём в начале, восточноарабские цифры с маркерами направления, время суток с *ص* / *م*, а также стандартные и левантийские составные названия месяцев:

```js
import '@native-dates/plugins/loose';
import { date, time, yearMonth } from 'native-dates';

date('06/11/2026', { loose: true, locale: 'ar-EG' })?.toString(); // '2026-11-06'
date('١٦‏/١١‏/٢٠٢٦', { loose: true, locale: 'ar-EG' })?.toString(); // '2026-11-16'
date('16 تشرين الثاني 2026', { loose: true, locale: 'ar-LB' })?.toString(); // '2026-11-16'
time('٢:٣٠ م', { loose: true, locale: 'ar-EG' })?.toString(); // '14:30:00'
yearMonth('تشرين الثاني 2026', { loose: true, locale: 'ar-LB' })?.toString(); // '2026-11'
```

[Плагин zones](/plugins/zones/) сразу распознаёт английские названия крупных городов Персидского залива и Северной Африки вместе с региональными аббревиатурами вроде `GST`. В локали `'ar-SA'` сокращение `AST` разрешается в Эр-Рияд:

```js
import '@native-dates/plugins/zones';
import { date, datetime } from 'native-dates';

datetime('2026-11-16T09:00', 'Makkah').zone; // 'Asia/Riyadh'
datetime('2026-11-16T09:00', 'Doha').zone; // 'Asia/Qatar'
datetime('2026-11-16T09:00', { zone: 'AST', locale: 'ar-SA' }).zone; // 'Asia/Riyadh'
```

Для расписаний используйте полные идентификаторы IANA, а не фиксированные смещения. В часовом поясе `'Africa/Casablanca'` часы переводят на час назад на время Рамадана, а в Каире переход на летнее время происходит в полночь со скачком сразу на 01:00:

```js
datetime('2026-02-14T12:00', 'Africa/Casablanca').offset; // '+01:00'
datetime('2026-03-01T12:00', 'Africa/Casablanca').offset; // '+00:00'
datetime('2026-03-25T12:00', 'Africa/Casablanca').offset; // '+01:00'

const cairoSpring = date('2026-04-24').at('00:00', 'Africa/Cairo');
cairoSpring.hour; // 1
cairoSpring.hoursInDay; // 23
```
