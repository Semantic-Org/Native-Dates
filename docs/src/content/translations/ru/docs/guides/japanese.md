Чтобы форматировать даты по-японски, передайте тег `'ja-JP'` любым способом из руководства [Локализация](/guides/localization/). Григорианские годы остаются форматом по умолчанию, а тег `'ja-u-ca-japanese'` при необходимости переключает пресеты на императорские эры.

## Императорские эры и первые годы

Передайте `'ja-u-ca-japanese'`, чтобы форматировать официальные даты с императорскими эрами — например, 31-й год Хэйсэй 30 апреля 2019 года и первый год Рэйва (*元年*) на следующий день:

```js
import { date } from 'native-dates';

date('2019-04-30').format('long', 'ja-u-ca-japanese'); // '平成31年4月30日'
date('2019-05-01').format('long', 'ja-u-ca-japanese'); // '令和元年5月1日'
date('2026-11-16').format('short', 'ja-u-ca-japanese'); // 'R8/11/16'
date('2026-11-16').format('llll', 'ja-u-ca-japanese'); // '令和8年11月16日(月)'
```

Шаблоны токенов вроде `'YYYY年M月D日'` и свойство `year` всегда читают григорианский год, даже если задана локаль с японским календарём. Когда нужны названия эр, используйте пресеты или объект параметров:

```js
const reiwa = date('2026-11-16').locale('ja-u-ca-japanese');

reiwa.year; // 2026
reiwa.format('long'); // '令和8年11月16日'
reiwa.format('YYYY年M月D日'); // '2026年11月16日'
```

У [`YearMonth`](/api/year-month/) нет дня месяца, поэтому он форматируется по эре, действовавшей 1-го числа. Для месяцев со сменой эры внутри, таких как январь 1989 года (переход с 64-го года Сёва на 1-й год Хэйсэй), сначала выберите день методом [`on()`](/api/year-month/#on):

```js
import { yearMonth } from 'native-dates';

const jan1989 = yearMonth('1989-01');

jan1989.format('long', 'ja-u-ca-japanese'); // '昭和64年1月'
jan1989.on(8).format('long', 'ja-u-ca-japanese'); // '平成元年1月8日'
```

## Дни недели в скобках и 12-часовой формат

Стандартные японские пресеты различаются разделителями и стилем дней недели:

| Пресет | Вывод | Стиль и типичное применение |
|---|---|---|
| `'medium'` | `'2026/11/16'` | Компактная запись через косую черту для таблиц и полей форм. |
| `'long'` | `'2026年11月16日'` | Стандартная дата с иероглифами в порядке год-месяц-день без дня недели. |
| `'full'` | `'2026年11月16日月曜日'` | Добавляет полное название дня недели вроде *月曜日* (понедельник) без пробелов и скобок. |
| `'llll'` | `'2026年11月16日(月)'` | Привычный для интерфейсов стиль с одним иероглифом дня недели *月* в полуширинных скобках. |

Токен `'ddd'` возвращает одиночный иероглиф дня недели вроде *月*, который можно заключить в полноширинные скобки. Токены полного месяца и порядкового дня уже дописывают *月* и *日*, поэтому сочетайте числовые токены с буквальными иероглифами:

```js
import { date } from 'native-dates';

const day = date('2026-11-16').locale('ja-JP');

day.format('YYYY年M月D日（ddd）'); // '2026年11月16日（月）'
day.format('MMMMDo(ddd)'); // '11月16日(月)'
day.format({ month: 'long', day: 'numeric', weekday: 'short' }); // '11月16日(月)'
```

Время суток по умолчанию выводится в 24-часовом формате. Передайте `hour12: true` для японской 12-часовой записи с нулём (*午前0:30* и *午後0:30*) или используйте `'Ah:mm'` для счёта часов от 1 до 12:

```js
import { datetime } from 'native-dates';

const midnight = datetime('2026-11-16T00:30', 'Asia/Tokyo').locale('ja-JP');

midnight.format('time'); // '0:30'
midnight.format({ hour: 'numeric', minute: '2-digit', hour12: true }); // '午前0:30'
midnight.format('Ah:mm'); // '午前12:30'
```

## Даты через косую черту и японский ввод

Иероглифические даты с годом в начале, а также записи через косую черту и точку из японских CSV и форм разбираются прямо в ядре без плагинов:

```js
import { date, datetime, yearMonth } from 'native-dates';

date('2026年11月16日').toString(); // '2026-11-16'
date('2026/1/5').toString(); // '2026-01-05'
datetime('2026年11月16日 9:30', 'Asia/Tokyo').toString(); // '2026-11-16T00:30:00.000Z'
yearMonth('2026年11月').toString(); // '2026-11'
```

С [плагином loose](/plugins/loose/) полноширинные цифры и знаки препинания, время с *午前* / *午後* и иероглифические пары месяц-день разбираются без предварительной нормализации:

```js
import '@native-dates/plugins/loose';
import { date, monthDay, time } from 'native-dates';

date('２０２６／１１／１６', { loose: true })?.toString(); // '2026-11-16'
time('午後2:30', { loose: true, locale: 'ja' })?.toString(); // '14:30:00'
monthDay('11月16日', { loose: true })?.toString(); // '11-16'
```

Строки с названием эры вроде `'令和8年11月16日'` пока требуют структурированного ввода. Когда форма собирает эру и год отдельными полями, передайте японский `Temporal.PlainDate` напрямую в [`date()`](/api/date-fn/) без ручной конвертации календаря:

```js
const reiwaInput = Temporal.PlainDate.from({
  calendar: 'japanese',
  era: 'reiwa',
  eraYear: 8,
  month: 11,
  day: 16,
});

date(reiwaInput).toString(); // '2026-11-16'
```

## Часовые пояса и начало недели

Ядро принимает `'Asia/Tokyo'` и фиксированные смещения. С [плагином zones](/plugins/zones/) аббревиатура `'JST'`, английские названия крупных японских городов (вроде `'Osaka'`) и встроенные японские псевдонимы (вроде `'東京'`) распознаются из коробки:

```js
import '@native-dates/plugins/zones';
import { datetime } from 'native-dates';

datetime('2026-11-16T09:30', 'JST').zone; // 'Asia/Tokyo'
datetime('2026-11-16T09:30', 'Osaka').zone; // 'Asia/Tokyo'
datetime('2026-11-16T09:30', '東京').zone; // 'Asia/Tokyo'
```

В японской локали неделя начинается с воскресенья, как на настенных календарях. Для рабочих расписаний с понедельника передавайте английское название `'monday'` или зафиксируйте `weekStart`:

```js
import { date, weekdayNames } from 'native-dates';

const wed = date('2026-11-18').locale('ja-JP');

wed.weekStart; // 7
wed.startOf('week').toString(); // '2026-11-15'
wed.startOf('week', 'monday').toString(); // '2026-11-16'
weekdayNames('short', undefined, 'ja-JP');
// ['日', '月', '火', '水', '木', '金', '土']
weekdayNames('short', 'monday', 'ja-JP');
// ['月', '火', '水', '木', '金', '土', '日']
```

## Диапазоны и относительные выражения

Пресеты диапазонов соединяют даты через косую черту или время с иероглифами полноширинной тильдой. Передайте шаблон токенов в [`format()`](/api/ranges/#format), если на обеих границах нужны иероглифические даты и дни недели:

```js
import { dateRange, timeRange } from 'native-dates';

const span = dateRange('2026-11-16', '2026-11-20').locale('ja-JP');

span.format('long'); // '2026/11/16～2026/11/20'
span.format('M月D日(ddd)'); // '11月16日(月) – 11月20日(金)'
timeRange('09:00', '17:30').format('short', 'ja-JP'); // '9時00分～17時30分'
```

[`CalendarDate`](/api/calendar-date/) возвращает естественные относительные обозначения вплоть до *一昨日* («позавчера») и *明後日* («послезавтра»). [`DateTime`](/api/date-time/) всегда выводит числовые единицы, чтобы разница в часах не отображалась как календарные дни:

```js
import { date, datetime, duration } from 'native-dates';

const baseDate = date('2026-11-16').locale('ja-JP');
baseDate.minus(2, 'days').from(baseDate); // '一昨日'
baseDate.plus(2, 'days').from(baseDate); // '明後日'

const baseTime = datetime('2026-11-16T12:00', 'Asia/Tokyo').locale('ja-JP');
baseTime.minus(1, 'day').from(baseTime); // '1 日前'
duration({ hours: 2, minutes: 30 }).format('long', 'ja-JP'); // '2 時間 30 分'
```

:::tip[Пробелы и кодовые точки полноширинной тильды]
По данным стандартного движка в японских относительных фразах и длительностях вокруг чисел стоят полуширинные пробелы. Пресеты диапазонов выводят полноширинную тильду `U+FF5E`, а не волнистое тире `U+301C` — учитывайте этот символ в проверках тестов.
:::
