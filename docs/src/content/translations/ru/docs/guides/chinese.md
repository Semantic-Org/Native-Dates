Передайте региональный тег вроде `'zh-CN'` или `'zh-TW'` одним из способов из руководства [Локализация](/guides/localization/). Каждый регион задаёт свою письменность, порядок компонентов даты, формат часов и первый день недели.

## Стандартное время Китая и сокращение CST

Для пекинского времени передавайте `'Asia/Shanghai'`. В отличие от фиксированного смещения UTC+8, этот идентификатор выводит локализованное название часового пояса *中国标准时间* и сохраняет исторические смещения летнего времени в Китае за 1986–1991 годы:

```js
import { datetime } from 'native-dates';

const release = datetime('2026-11-16T09:30:00Z', 'Asia/Shanghai').locale('zh-CN');

release.format('YYYY-MM-DD HH:mm zzzz'); // '2026-11-16 17:30 中国标准时间'
datetime('1988-07-15T00:00:00Z', 'Asia/Shanghai').offset; // '+09:00'
```

С [плагином zones](/plugins/zones/) аббревиатура `CST` подстраивается под активную локаль: в материковом Китае она разрешается в Шанхай, а на Тайване — в Тайбэй. Английские названия крупных городов материкового Китая и встроенные китайские псевдонимы вроде `'北京'` распознаются из коробки, при этом Урумчи остаётся на синьцзянском времени UTC+6:

```js
import '@native-dates/plugins/zones';
import { datetime } from 'native-dates';

datetime('2026-11-16T09:30:00Z', { zone: 'CST', locale: 'zh-CN' }).zone; // 'Asia/Shanghai'
datetime('2026-11-16T09:30:00Z', { zone: 'CST', locale: 'zh-TW' }).zone; // 'Asia/Taipei'
datetime('2026-11-16T09:30:00Z', 'Beijing').zone; // 'Asia/Shanghai'
datetime('2026-11-16T09:30:00Z', 'Shenzhen').format('HH:mm', 'zh-CN'); // '17:30'
datetime('2026-11-16T09:30:00Z', 'Urumqi').offset; // '+06:00'
```

## Региональные различия

Материковый Китай, Тайвань, Гонконг, Макао и Сингапур различаются форматом времени суток по умолчанию, порядком компонентов в краткой дате, иероглифами дней недели и первым днём недели:

| Тег локали | Краткая дата | Начало недели | Формат времени и обозначения дней недели |
|---|---|---|---|
| `zh-CN` | `2026/11/16` | Понедельник | 24-часовой формат по умолчанию и упрощённые иероглифы от `周一` до `周日` (пн–вс). |
| `zh-TW` | `2026/11/16` | Воскресенье | 12-часовой формат с `上午` и `下午` (AM/PM) и традиционные обозначения дней недели `週一`. |
| `zh-HK` | `16/11/2026` | Воскресенье | 12-часовой формат и краткие даты с днём в начале, как и в Макао. |
| `zh-SG` | `16/11/26` | Воскресенье | 12-часовой формат, упрощённые дни недели с `周` и двузначный год в датах с днём в начале. |

Один и тот же момент времени выводится по правилам каждого региона:

```js
import { datetime } from 'native-dates';

const meeting = datetime('2026-11-16T17:05:00+08:00', 'Asia/Shanghai');

meeting.format('medium', 'zh-CN'); // '2026年11月16日 17:05'
meeting.format('medium', 'zh-TW'); // '2026年11月16日 下午5:05'
meeting.date.format('short', 'zh-HK'); // '16/11/2026'
meeting.date.format('short', 'zh-SG'); // '16/11/26'
```

В воскресенье материковый Китай завершает текущую неделю, тогда как Тайвань, Гонконг и Сингапур начинают новую. Чтобы ключи общих еженедельных отчётов совпадали, передавайте английское название `'monday'` в [`startOf()`](/api/calendar-date/#startof):

```js
import { date } from 'native-dates';

const sunday = date('2026-11-15');

sunday.locale('zh-CN').range('week').toString(); // '2026-11-09/2026-11-15'
sunday.locale('zh-HK').range('week').toString(); // '2026-11-15/2026-11-21'
sunday.locale('zh-HK').startOf('week', 'monday').toString(); // '2026-11-09'
```

В упрощённом китайском шаблон `'Ah:mm'` выводит *上午* или *下午*. Параметр `dayPeriod: 'short'` включает естественные обозначения частей суток: предрассветное время *凌晨*, утро *早上*, полдень *中午* и вечер *晚上*:

```js
import { time } from 'native-dates';

const night = time('20:30').locale('zh-CN');

night.format('short'); // '20:30'
night.format('Ah:mm'); // '下午8:30'
night.format({
  hour: 'numeric',
  minute: '2-digit',
  hour12: true,
  dayPeriod: 'short',
}); // '晚上8:30'
```

## Шаблоны форматирования и разбор ввода

В шаблонах токенами считаются только латинские буквы, поэтому *年*, *月*, *日* и китайскую пунктуацию не нужно брать в квадратные скобки. `'MMMM'` выводит месяцы иероглифами вроде *十一月*, а `'dd'` — краткие дни недели из одного иероглифа:

```js
import { datetime } from 'native-dates';

const slot = datetime('2026-11-06T14:05:00+08:00', 'Asia/Shanghai').locale('zh-CN');

slot.format('YYYY年M月D日 ddd HH:mm'); // '2026年11月6日 周五 14:05'
slot.format('MMMDo / MMMMDo'); // '11月6日 / 十一月6日'
slot.format('dd / ddd / dddd'); // '五 / 周五 / 星期五'
slot.format('ddd', 'zh-TW'); // '週五'
```

Фабричные функции ядра напрямую разбирают иероглифические даты с годом в начале, а также записи через косую черту и точку — длинный пресет разбирается обратно без плагинов. Для гонконгских дат через косую черту с днём в начале, полноширинных цифр, времени суток с обозначением части дня или сокращения `CST` внутри строки подключите [плагин loose](/plugins/loose/):

```js
import '@native-dates/plugins/loose';
import '@native-dates/plugins/zones';
import { date, datetime, monthDay, time, yearMonth } from 'native-dates';

date('2026年11月16日').toString(); // '2026-11-16'
yearMonth('2026年11月').toString(); // '2026-11'
date('16/11/2026', { loose: true, locale: 'zh-HK' })?.toString(); // '2026-11-16'
date('２０２６年１１月１６日', { loose: true })?.toString(); // '2026-11-16'
time('下午5:05', { loose: true, locale: 'zh-TW' })?.toString(); // '17:05:00'
time('晚上9:10', { loose: true, locale: 'zh-CN' })?.toString(); // '21:10:00'
time('凌晨12:00', { loose: true, locale: 'zh-TW' })?.toString(); // '00:00:00'
monthDay('11月16日', { loose: true })?.toString(); // '11-16'
datetime('2026年11月16日 14:30 CST', {
  loose: true,
  locale: 'zh-CN',
  zone: 'UTC',
})?.toString(); // '2026-11-16T06:30:00.000Z'
```

Нестрогий режим распознаёт и *上午* / *下午*, и слова для частей суток (*凌晨*, *中午*, *晚上*) в обеих локалях — `'zh-CN'` и `'zh-TW'`.

## Китайский лунный календарь и календарь Миньго

Передайте `'zh-CN-u-ca-chinese'` при форматировании даты или момента времени, чтобы пресеты выводили годы по шестидесятилетнему циклу, первый месяц *正月* и високосные месяцы вроде *闰六月*.

Шаблоны токенов всегда читают григорианские поля. Частичные даты используют григорианский календарь по умолчанию, так как у них нет дня месяца, а тайваньский календарь Миньго (`'zh-TW-u-ca-roc'`) совпадает с григорианскими месяцами:

```js
import { date, yearMonth } from 'native-dates';

date('2026-02-17').format('long', 'zh-CN-u-ca-chinese'); // '2026丙午年正月初一'
date('2025-07-25').format('medium', 'zh-CN-u-ca-chinese'); // '2025年闰六月初一'
date('2026-02-17').format('YYYY-MM-DD', 'zh-CN-u-ca-chinese'); // '2026-02-17'
yearMonth('2026-02').format('long', 'zh-CN-u-ca-chinese'); // '2026年2月'
yearMonth('2026-11').format('long', 'zh-TW-u-ca-roc'); // '民國115年11月'
```

## Относительное время

[`CalendarDate`](/api/calendar-date/) считает календарные дни и возвращает *前天* («позавчера») и *后天* («послезавтра»). [`DateTime`](/api/date-time/) считает прошедшие секунды, поэтому 23 часа назад никогда не превращаются во «вчера»:

```js
import { date, datetime, today } from 'native-dates';

const base = date('2026-11-16');
date('2026-11-14').from(base, 'zh-CN'); // '前天'
date('2026-11-18').from(base, 'zh-CN'); // '后天'

const anchor = datetime('2026-11-16T12:00:00+08:00', 'Asia/Shanghai');
anchor.minus(2, 'days').from(anchor, 'zh-CN'); // '2天前'
date('2026-11-18').from(today('Asia/Shanghai'), 'zh-CN');
```

На серверах в UTC вызов [`fromNow()`](/api/calendar-date/#fromnow) без аргументов с полуночи до 8:00 по Пекину попадает на предыдущий день по UTC, поэтому передавайте [`today('Asia/Shanghai')`](/api/date-fn/#today) явно.
