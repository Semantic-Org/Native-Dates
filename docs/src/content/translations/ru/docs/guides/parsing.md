Ядро напрямую разбирает стандартные, однозначные входные данные в тот тип, который вы запрашиваете:

- [`datetime()`](/api/datetime-fn/) — моменты времени, миллисекунды от эпохи Unix и метки времени
- [`date()`](/api/date-fn/) — календарные даты без времени суток и часового пояса
- [`time()`](/api/time-fn/) — время суток в 24-часовом и 12-часовом форматах
- [`duration()`](/api/duration-fn/) — английские фразы длительности и длительности ISO 8601
- [`yearMonth()`](/api/year-month-fn/) и [`monthDay()`](/api/month-day-fn/) — расчётные месяцы, сроки действия карт и повторяющиеся дни рождения
- [`dateRange()`](/api/range-fn/#daterange), [`datetimeRange()`](/api/range-fn/#datetimerange) и [`timeRange()`](/api/range-fn/#timerange) — интервалы и пары границ

## Даты ISO и метки времени

Передайте в `date()` строку с годом в начале, три числа (год, месяц и день) либо объект с полями. В строках с годом в начале допускаются однозначные и двузначные номера месяца и дня с любым разделителем, кроме латинских букв и двоеточий. Китайские, японские, корейские даты и даты с точками и пробелами ядро разбирает напрямую.

Месяцы нумеруются от 1 до 12. Несуществующие календарные даты вроде 30 февраля, а также недельные и квартальные строки ISO вроде `'2026-W05-1'` выбрасывают ошибку вместо молчаливых догадок.

```js
import { date } from 'native-dates';

date('2026-11-16');
date('2026/11/6');
date('2026年11月16日');
date('2026. 11. 16.');
date(2026, 11, 16);
date({ year: 2026, month: 11, day: 16 });
```

В `datetime()` передавайте строки ISO 8601 или объекты с полями. Суффикс `Z` или числовое смещение UTC задаёт точный момент времени, а строка без смещения трактуется как местное время в целевом часовом поясе.

```js
import { datetime } from 'native-dates';

datetime('2026-11-16T17:30:00Z', 'America/Los_Angeles'); // 9:30 AM PST
datetime('2026-11-16T09:30', 'America/Los_Angeles'); // 9:30 AM PST
datetime('2026-11-16T09:30[Europe/Berlin]'); // 9:30 AM CET
datetime({ year: 2026, month: 11, day: 16, hour: 9, minute: 30 }, 'Europe/Berlin');
```

Если передать метку времени со смещением в `date()` или `time()`, функция извлечёт её календарный день или местное время суток в указанном часовом поясе:

```js
import { time } from 'native-dates';

date('2026-11-17T01:30:00Z', 'America/Los_Angeles'); // 2026-11-16
date('2026-11-17T01:30:00Z', 'Asia/Tokyo'); // 2026-11-17
time('2026-11-17T01:30:00Z', 'America/Los_Angeles'); // 17:30:00
```

## Время суток и длительности

В `time()` передавайте 24-часовые строки ISO, записи с часами и минутами вроде `'14h30'`, 12-часовой формат, числовые аргументы или объект с полями. Одиночный час вроде `'14h'` по-прежнему выбрасывает ошибку, чтобы длительности оставались однозначными.

```js
import { time } from 'native-dates';

time('09:30');
time('14h30');
time('9:30am');
time('5:15 PM');
time(17, 15, 30);
time({ hour: 9, minute: 30 });
```

В `duration()` передавайте английские фразы длительности, строки длительности ISO 8601, число с единицей измерения либо объект с полями.

```js
import { duration } from 'native-dates';

duration('1h 30m');
duration('2 weeks and 3 days');
duration('PT90M');
duration(90, 'minutes');
duration({ hours: 1, minutes: 30 });
```

## Частичные даты и диапазоны

Передавайте строки ISO с годом и месяцем в [`yearMonth()`](/api/year-month-fn/), а для сроков действия карт, где месяц идёт первым, используйте [`monthYear()`](/api/year-month-fn/#monthyear):

```js
import { dayMonth, monthDay, monthYear, yearMonth } from 'native-dates';

yearMonth('2026-11');
monthYear('11/28'); // YearMonth(2028-11)

monthDay('10/17');
dayMonth('17/10'); // MonthDay(10-17)
```

Повторяющиеся даты без года работают точно так же через [`monthDay()`](/api/month-day-fn/) и [`dayMonth()`](/api/month-day-fn/#daymonth). Для промежутков [фабричные функции диапазонов](/api/range-fn/) принимают две границы или одну строку интервала:

```js
import { dateRange, timeRange } from 'native-dates';

dateRange('2026-11-01/2026-11-07');
timeRange('9am - 5pm');
```

## Метки эпохи Unix, Date и Temporal

Миллисекунды от эпохи Unix, встроенные объекты `Date` и объекты [Temporal](/guides/temporal/) можно передавать напрямую в `datetime()`.

Передача одного числа в фабричную функцию даты выбрасывает ошибку из-за неоднозначности. Сначала преобразуйте миллисекунды от эпохи Unix в момент времени в нужном часовом поясе, а затем возьмите его календарную дату.

```js
import { date, datetime } from 'native-dates';

const fromEpoch = datetime(1794850200000, 'UTC');
const fromJSDate = datetime(new Date('2026-11-16T17:30:00Z'));
const localDay = date(new Date('2026-11-16T17:30:00Z'), 'America/Los_Angeles');
```

## Почему неоднозначные строки выбрасывают ошибку

У строки с четырёхзначным годом в начале есть ровно одно прочтение, тогда как `'03/05/2026'` означает 5 марта в США и 3 мая в Европе и Латинской Америке. Ядро отклоняет неоднозначные числовые строки, чтобы не угадать неверный месяц в продакшене.

:::warning[Пустые значения никогда не подставляют текущий момент]
Передача пустого значения в любую фабричную функцию выбрасывает ошибку вместо возврата текущей даты или момента времени, поэтому отсутствующее поле из API никогда не притворится сегодняшним днём. Вызовите [`now()`](/api/datetime-fn/#now) или [`today()`](/api/date-fn/#today), если нужен текущий момент времени или сегодняшняя дата.
:::

## Пользовательский ввод с плагином loose

Для разбора произвольного текста из пользовательских полей ввода, CSV-выгрузок или заголовков RFC 2822 подключите [`@native-dates/plugins/loose`](/plugins/loose/) и передайте `{ loose: true }`. Нестрогий режим разбирает даты и время суток в формате активной локали, включая локализованные названия месяцев, обозначения части суток, время через точку и нелатинские цифры.

```js
import '@native-dates/plugins/loose';
import { date, datetime, monthDay, time, yearMonth } from 'native-dates';

date('Nov 16, 2026', { loose: true }); // 2026-11-16
date('16 de noviembre de 2026', { loose: true, locale: 'es' }); // 2026-11-16
datetime('Mon, 16 Nov 2026 17:30:00 GMT', { loose: true });
time('오후 2:30', { loose: true, locale: 'ko' }); // 14:30:00
yearMonth('Nov 2026', { loose: true }); // 2026-11
monthDay('17 février', { loose: true, locale: 'fr' }); // 02-17
```

Порядок компонентов в числовых датах со слешами и точками определяется активной локалью. Передайте `dayFirst` в конкретный вызов или задайте его в [настройках приложения](/api/configure/), если порядок во входных данных отличается от активной локали.

```js
date('03/05/2026', { loose: true, locale: 'en-US' }); // 2026-03-05
date('03/05/2026', { loose: true, locale: 'fr' }); // 2026-05-03
date('03/05/2026', { loose: true, locale: 'en-US', dayFirst: true }); // 2026-05-03
```

В нестрогом режиме нераспознанный ввод возвращает `null` вместо ошибки во всех фабричных функциях и диапазонах. Некорректные значения параметров — например, неизвестное имя часового пояса — по-прежнему выбрасывают ошибку.

```js
import { duration } from 'native-dates';

date('not a date', { loose: true }); // null
duration('soon', { loose: true }); // null
```
