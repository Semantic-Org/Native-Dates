По умолчанию Native Dates использует локальный часовой пояс и локаль среды выполнения. Используйте [`configure()`](/api/configure/) и подключаемые плагины, если приложению нужны фиксированные значения по умолчанию, именованные форматы или дополнительные возможности разбора и работы с поясами.

## Настройки приложения по умолчанию

Вызовите [`configure()`](/api/configure/) при запуске, чтобы задать часовой пояс, локаль или первый день недели (английским названием вроде `'monday'`) для всего приложения. Неуказанные ключи сохраняют текущее значение, а передача `null` возвращает значение по умолчанию из среды выполнения:

```js title="main.js"
import { configure, date, now } from 'native-dates';

configure({
  zone: 'America/New_York',
  locale: 'en-US',
  weekStart: 'monday',
});

now().zone; // 'America/New_York'
date('2026-11-18').startOf('week').toString(); // '2026-11-16'
```

В любом отдельном вызове по-прежнему можно задать собственный часовой пояс, локаль через [`locale()`](/api/date-time/#locale) или начало недели, чтобы переопределить глобальную настройку.

:::warning[Настраивайте сервер один раз при запуске]
Глобальные настройки общие для всего процесса JavaScript. На многопользовательском сервере привязывайте часовой пояс и локаль каждого запроса к конкретному значению, а не меняйте глобальные настройки через `configure()` при каждом запросе.
:::

## Именованные форматы

Зарегистрируйте именованные форматы в поле `formats` и передавайте их названия в [`format()`](/guides/formatting/). В качестве значения подойдёт шаблон токенов или объект параметров `Intl`:

```js title="main.js"
import { configure, date, datetime } from 'native-dates';

configure({
  formats: {
    invoice: 'YYYY-MM-DD',
    receipt: { weekday: 'long', month: 'long', day: 'numeric' },
  },
});

date('2026-11-06').format('invoice'); // '2026-11-06'
const placed = datetime('2026-11-06T09:05', 'Europe/Berlin');
placed.format('receipt'); // 'Friday, November 6'
```

Именованные форматы работают с датами, временем суток, моментами времени, частичными датами и диапазонами, тогда как длительности поддерживают только встроенные стили. Пользовательские имена имеют приоритет над встроенными пресетами: регистрация `'short'` переопределит этот пресет во всём приложении.

## Подключение плагинов

Дополнительные плагины для поиска часовых поясов по городам, нестрогого разбора и геттеров устаревшего `Date` находятся в [`@native-dates/plugins`](/plugins/):

```bash
npm i @native-dates/plugins
```

Импортируйте нужную точку входа один раз при запуске приложения:

```js title="main.js"
import '@native-dates/plugins/loose';
import '@native-dates/plugins/zones';
import { date, datetime } from 'native-dates';

datetime('2026-11-16T09:30', 'Berlin').zone; // 'Europe/Berlin'
date('Nov 16, 2026', { loose: true }); // CalendarDate(2026-11-16)
```

Подключённые плагины расширяют набор параметров [`configure()`](/api/configure/). Плагин `zones` добавляет `zoneAliases` для пользовательских псевдонимов (в дополнение к английским названиям городов, аббревиатурам и встроенным национальным псевдонимам вроде `'москва'`, `'мск'`, `'東京'`, `'北京'`, `'서울'`), а плагин `loose` — параметр `dayFirst` для порядка дня и месяца в числовых датах:

```js title="main.js"
import '@native-dates/plugins/loose';
import '@native-dates/plugins/zones';
import { configure, date, now } from 'native-dates';

configure({
  zoneAliases: { hq: 'Europe/Berlin' },
  dayFirst: true,
});

now('hq').zone; // 'Europe/Berlin'
date('07.09.2026', { loose: true }).toString(); // '2026-09-07'
```

Откройте [обзор плагинов](/plugins/), чтобы посмотреть размер каждой точки входа, или прочитайте руководство [Написание плагина](/guides/writing-a-plugin/), чтобы создать свой плагин.

## Пользовательские названия дней недели и порядковые числа

Названия месяцев и дней недели берутся из встроенных данных `Intl`. Если по дизайну нужны особые сокращения дней недели или порядковые формы чисел, переопределите их через `weekdayNames` (с английскими ключами дней недели) и `ordinals`:

```js title="main.js"
import { configure, date } from 'native-dates';

configure({
  weekdayNames: {
    en: { short: { tue: 'Tues', thu: 'Thurs' } },
  },
  ordinals: {
    fr: (day) => (day === 1 ? '1er' : day),
  },
});

date('2026-11-03').format('ddd', 'en-US'); // 'Tues'
date('2026-11-01').format('Do MMMM', 'fr'); // '1er novembre'
```

Передайте `null` в любое из этих полей, чтобы вернуться к значениям среды выполнения и встроенным правилам. Далее прочитайте руководство [Локализация](/guides/localization/) о локалях пользователей, границах недель и календарных системах.
