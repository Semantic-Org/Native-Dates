Планирование начинается с `tomorrow().at(input.value)` — соединения завтрашней календарной даты с выбранным временем суток. Этот единый момент времени (`DateTime`) задаёт весь список без ручных смещений UTC.

Для каждого города `meeting.in(zone)` переводит тот же момент времени в нужный часовой пояс IANA, а `format('time')` выводит его местное время суток.

Сравнение `there.date` с датой организатора определяет, перешёл ли город через полночь. Подпись дня недели появляется в строке только тогда, когда дата отличается.
