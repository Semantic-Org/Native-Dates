Целевой момент времени вычисляется через `today().next('friday').at('5pm')` (метод `next()` принимает английские названия дней недели): выражение переходит к ближайшей пятнице и устанавливает местное время суток на 17:00.

Каждую секунду `now().until(launch)` вычисляет оставшуюся длительность в днях, часах, минутах и секундах. Вызов `round('second')` убирает миллисекунды, чтобы таймер обновлялся ровно по секундам.

Наконец, `format()` выводит ту же длительность словами вместе с узким и цифровым стилями таймера без ручного пересчёта из миллисекунд.
