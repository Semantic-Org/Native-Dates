Одного вызова `configure({ locale: 'ar-EG' })` достаточно, чтобы включить арабские формы множественного числа и восточноарабские цифры для всех значений. Чтение `days(2).text` выводит форму двойственного числа вообще без цифры.

Добавьте `.locale('ar-MA')`, когда отдельное значение и производные от него диапазоны должны выводиться западными цифрами с марокканскими названиями месяцев, а остальное приложение сохраняет настроенную локаль по умолчанию.

Передача `'ar-SA-u-ca-islamic-umalqura'` переводит любую календарную дату в саудовский календарь Хиджры Умм аль-Кура, а `day.monthDay` сохраняет рядом григорианский ориентир.

При вставке арабского текста в страницу с направлением слева направо оборачивайте каждое отформатированное значение в `<bdi>`, чтобы цифры и тире в диапазонах сохраняли порядок справа налево.
