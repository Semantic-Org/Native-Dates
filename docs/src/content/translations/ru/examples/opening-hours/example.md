Каждое заведение задаёт график работы как диапазон времени суток `timeRange(open, close)` по своим местным часам. Когда закрытие раньше открытия, диапазон автоматически переходит через полночь.

Для выбранного времени суток выражение `today().at(input.value)` создаёт момент времени (`DateTime`), а `in(place.zone)` переводит этот момент времени в часовой пояс заведения.

После этого проверка `hours.contains(local.time)` отвечает, открыто ли заведение, без особых условий для ночных смен и ручной арифметики UTC.
