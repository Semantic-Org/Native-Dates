Одного вызова `configure({ locale: 'ja' })` достаточно, чтобы включить японский формат во всех текстовых свойствах и пресетах. Стандартные пресеты сочетают числа без ведущих нулей со счётными иероглифами, а `day.yearMonth` убирает счётчик дня для заголовков месяцев.

Диапазоны дат и ночные диапазоны `timeRange()` автоматически используют ту же настроенную локаль. Оба типа соединяют границы японской волнистой чертой без подстановки фиктивных календарных дат при переходе через полночь.

Передавайте явный тег локали только при переходе на другой календарь. Тег `'ja-u-ca-japanese'` форматирует дату по японскому императорскому календарю и выводит `元年` для первого года каждой эры.
