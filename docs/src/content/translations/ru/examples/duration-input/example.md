Передача пользовательского текста в `duration()` разбирает английские фразы длительности и строки ISO 8601 в одно структурированное значение.

Затем `format()` записывает длительность словами, а `total('hours')` переводит её в одно десятичное число. Подстановка в строку возвращает стандартный формат ISO 8601, готовый для базы данных или тела API-запроса.

При нечитаемом вводе выбрасывается ошибка: `error.message` указывает на некорректное значение и сразу показывает на странице примеры правильной записи.
