把用户输入直接传入 `duration()`，即可将常见的英文单位短语和 ISO 8601 字符串统一解析为结构化的时长值。

随后，`format()` 将时长格式化为可读文字，`total('hours')` 把整段时长换算为单个小数值，字符串插值则直接输出适用于数据库或 API 载荷的标准 ISO 8601 格式。

遇到无法解析的输入时会抛出错误，其 `error.message` 会指出无效内容并在页面中直接展示合法示例。
