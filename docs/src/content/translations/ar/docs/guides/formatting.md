تعتمد Native Dates على منسّقات `Intl` المدمجة في بيئة التشغيل وتخزّنها مؤقتًا تلقائيًا، فتحصل على إخراج موطّن عبر اللغات والأقاليم من دون إضافة ملفات إعدادات محلية إلى حزمتك.

## إخراج سريع عبر text والقوالب الجاهزة

يحمل كل كائن خاصية `.text` منسّقة بالإعداد المحلي النشط. ويستخدم استدعاء [`format()`](/api/date-time/#format) بلا معاملات القالب الجاهز الافتراضي لكل نوع:

```js
import { date, datetime, duration, time } from 'native-dates';

const standup = datetime('2026-11-16T09:30', 'America/Los_Angeles');
standup.text; // 'Nov 16, 2026, 9:30 AM PST'
standup.format(); // 'Nov 16, 2026, 9:30 AM'

date('2026-11-16').text; // 'Nov 16, 2026'
time('9:30am').text; // '9:30 AM'
duration('1h 30m').text; // '1 hour, 30 minutes'
```

مرّر اسم قالب جاهز إلى `format()` لتحديد مستوى التفصيل المعروض:

| القالب الجاهز | مثال | الأنواع المدعومة والمخرجات |
|---|---|---|
| `'short'` | `'5/4/26, 9:30 AM'` | تاريخ رقمي أو وقت ساعة مختصر عبر التواريخ والأوقات والتواريخ الجزئية والمدد الزمنية. |
| `'medium'` | `'May 4, 2026, 9:30 AM'` | اسم شهر مختصر على التواريخ واللحظات الزمنية، أو وقت ساعة بالثواني على [`Time`](/api/time/). |
| `'long'` | `'May 4, 2026 at 9:30 AM'` | اسم شهر كامل، أو وقت ساعة بالثواني على `Time`، أو وحدات مكتوبة بالكامل على [`Duration`](/api/duration/). |
| `'full'` | `'Monday, May 4, 2026 at 9:30 AM'` | يوم الأسبوع والشهر بالكامل على التواريخ واللحظات الزمنية، أو الشهر كاملًا على التواريخ الجزئية. |
| `'date'` | `'May 4, 2026'` | جزء التاريخ في [`DateTime`](/api/date-time/) و[`CalendarDate`](/api/calendar-date/). |
| `'time'` | `'9:30 AM'` | وقت الساعة المختصر في `DateTime` و`Time`. |
| `'month'` | `'May 2026'` | اسم الشهر كاملًا والسنة في `DateTime` و`CalendarDate` و[`YearMonth`](/api/year-month/). |
| `'text'` | `'May 4, 2026, 9:30 AM PDT'` | التاريخ والوقت واسم المنطقة الزمنية المختصر في `DateTime`، أو حقول كل نوع في غيره. |

:::details[أسماء القوالب الجاهزة في Moment وDay.js]
تقبل النواة أيضًا أسماء القوالب الجاهزة الموطّنة المستعملة في Moment وDay.js:

| القالب الجاهز | مثال | الحقول الموطّنة |
|---|---|---|
| `'LT'`، `'LTS'` | `'9:30 AM'`، `'9:30:00 AM'` | وقت ساعة مختصر، أو وقت ساعة مع الثواني. |
| `'L'`، `'l'` | `'05/04/2026'`، `'5/4/2026'` | السنة والشهر واليوم رقميًا، مع حشو الأصفار أو بدونه. |
| `'LL'`، `'ll'` | `'May 4, 2026'` | اسم الشهر الكامل أو المختصر مع اليوم والسنة. |
| `'LLL'`، `'lll'` | `'May 4, 2026 at 9:30 AM'` | تاريخ طويل أو مختصر مقترن بوقت ساعة مختصر. |
| `'LLLL'`، `'llll'` | `'Monday, May 4, 2026 at 9:30 AM'` | يوم الأسبوع الكامل أو المختصر مع التاريخ ووقت الساعة المختصر. |
:::

تقبل التواريخ والأوقات وقيم [السنة والشهر](/api/year-month/) وقيم [الشهر واليوم](/api/month-day/) كل قالب جاهز أعلاه وتحتفظ فقط بالحقول التي تحملها. وتدعم [المدد الزمنية](/api/duration/) أيضًا القالبين المضغوط والرقمي:

```js
import { date, duration, time, yearMonth } from 'native-dates';

date('2026-11-16').format('full', 'en-US'); // 'Monday, November 16, 2026'
yearMonth('2026-11').format('LL', 'en-US'); // 'November 2026'
time('9:30:15am').format('LTS', 'en-US'); // '9:30:15 AM'

const span = duration({ hours: 2, minutes: 15 });
span.format('narrow', 'en-US'); // '2h 15m'
span.format('digital', 'en-US'); // '2:15:00'
```

## الإعدادات المحلية وخيارات Intl

اضبط إعدادًا افتراضيًا مرة واحدة عبر [`configure()`](/api/configure/)، أو أرفق إعدادًا محليًا بقيمة عبر [`locale()`](/api/date-time/#locale)، أو مرّر وسمًا إلى استدعاء تنسيق واحد. اقرأ [التوطين](/guides/localization/) لمعرفة الفارق بين تطبيقات العميل والخوادم متعدّدة المستخدمين:

```js
import { configure, datetime } from 'native-dates';

const standup = datetime('2026-11-16T09:30', 'Europe/Berlin');
standup.locale('de-DE').plus(1, 'week').format('long'); // '23. November 2026 um 09:30'
standup.format('long', 'ja-JP'); // '2026年11月16日 9:30'

configure({ locale: 'en-GB' });
configure({ locale: null });
```

وعندما لا يناسب أي قالب جاهز تخطيطك، مرّر كائن خيارات مباشرةً إلى المنسّق الأساسي:

```js
import { date } from 'native-dates';

const day = date('2026-11-16');

day.format({ weekday: 'long' }, 'en-US'); // 'Monday'
day.format({ month: 'short', day: 'numeric' }, 'en-US'); // 'Nov 16'
```

لأن كل نوع يحمل حقوله فقط، تتكيّف القوالب الجاهزة مع القواعد النحوية المحلية وصيغ الجمع وأنظمة الكتابة والتقويمات من دون ملفات إعدادات محلية. تصفّح [أمثلة اللغات](/examples/) للتحقق من الحالات الخاصة في لغتك المستهدفة:

```js
import { date, days, yearMonth } from 'native-dates';

date('2019-05-01').format('long', 'ja-u-ca-japanese'); // '令和元年5月1日'
yearMonth('2026-05').format('long', 'ru'); // 'май 2026 г.'
date('2026-05-01').format('long', 'ru'); // '1 мая 2026 г.'
days(2).format('long', 'ar'); // 'يومان'
```

:::tip[العرض البشري مقابل نصوص النقل]
خصص `format()` للنصوص المعروضة للبشر. وعند تخزين القيم أو إرسالها عبر الشبكة، استدعِ [`toString()`](/api/date-time/#tostring) أو حوّلها إلى JSON كي تبقى الحمولات بتنسيق ISO 8601 ثابت. راجع [التخزين والإرسال](/guides/storing-and-sending/).
:::

## أنماط الرموز

عندما تحتاج تنسيقًا ثابتًا، مرّر نمط رموز إلى `format()`. ضع الكلمات الحرفية بين قوسين معقوفين لتُنسخ كما هي:

```js
import { datetime, monthDay, yearMonth } from 'native-dates';

const standup = datetime('2026-11-16T09:30', 'America/Los_Angeles');

standup.format('YYYY-MM-DD HH:mm'); // '2026-11-16 09:30'
standup.format('YYYY-MM-DDTHH:mmZ'); // '2026-11-16T09:30-08:00'
standup.format('dddd, MMM D [at] h:mm A', 'en-US'); // 'Monday, Nov 16 at 9:30 AM'
yearMonth('2026-11').format('MMM YYYY', 'en-US'); // 'Nov 2026'
monthDay('11-16').format('MMMM Do', 'en-US'); // 'November 16th'
```

تأتي أسماء الأشهر وأيام الأسبوع داخل أنماط الرموز من `Intl` وفق الإعداد المحلي النشط، بينما تبقى الأرقام والسنوات بالأرقام الغربية القياسية لـ ISO كي تظل أنماط مثل `'YYYY-MM-DD'` قابلة للقراءة البرمجية في كل مكان. وتتبع الرموز حالة الأحرف المعتمدة في Moment وDay.js (`YYYY` و`DD` بأحرف كبيرة، بخلاف أحرف LDML وdate-fns الصغيرة `yyyy` و`dd`، حيث يرمز `dd` هنا إلى اسم يوم الأسبوع المختصر بحرفين).

:::details[جميع رموز التنسيق]
| الرمز | مثال | المخرجات |
|---|---|---|
| `YYYY` | `'2026'` | سنة من 4 أرقام، مسبوقة بإشارة سالب للسنوات السالبة. |
| `YY` | `'26'` | سنة من رقمين. |
| `Q` | `'4'` | ربع السنة التقويمي من 1 إلى 4. |
| `M`، `MM` | `'11'`، `'05'` | رقم الشهر بلا حشو أو محشوًا بصفر إلى رقمين. |
| `MMM`، `MMMM` | `'Nov'`، `'November'` | اسم الشهر الميلادي الموطّن، يتصرّف إعرابيًا تلقائيًا بعد رمز اليوم حتى لو فصل بينهما نص حرفي. |
| `D`، `DD` | `'5'`، `'05'` | يوم الشهر بلا حشو أو محشوًا بصفر. |
| `Do` | `'16th'` | يوم الشهر بلاحقة ترتيبية في الإنجليزية، أو علامة اليوم المحلية مثل `'6.'` أو `'6日'`، أو عبر خيار [`ordinals`](/api/configure/) المخصّص. |
| `DDD`، `DDDD` | `'320'`، `'045'` | يوم السنة بلا حشو أو محشوًا بأصفار إلى 3 أرقام. |
| `E` | `'7'` | يوم الأسبوع وفق معيار ISO من 1 ليوم الاثنين إلى 7 ليوم الأحد، مطابقًا لـ `dayOfWeek`. |
| `d` | `'0'` | يوم الأسبوع من 0 ليوم الأحد إلى 6 ليوم السبت، مطابقًا لـ Moment وDay.js. |
| `dd`، `ddd`، `dddd` | `'Mo'`، `'Mon'`، `'Monday'` | أقصر اسم موطّن ليوم الأسبوع (حرف واحد أو حرفان حسب نظام الكتابة)، أو المختصر، أو الكامل، قابل للتخصيص عبر [`weekdayNames`](/api/configure/). |
| `W`، `WW` | `'47'`، `'05'` | رقم أسبوع ISO في السنة بلا حشو أو محشوًا بصفر. |
| `H`، `HH` | `'9'`، `'09'` | الساعة بنظام 24 ساعة بلا حشو أو محشوة بصفر. |
| `h`، `hh` | `'9'`، `'09'` | الساعة بنظام 12 ساعة من 1 إلى 12. |
| `m`، `mm` | `'5'`، `'05'` | الدقيقة بلا حشو أو محشوة بصفر. |
| `s`، `ss` | `'8'`، `'08'` | الثانية بلا حشو أو محشوة بصفر. |
| `S`، `SS`، `SSS` | `'4'`، `'42'`، `'420'` | أعشار أو أجزاء من مئة أو مللي ثانية. |
| `A`، `a` | `'AM'`، `'am'` | `'AM'` و`'PM'` بأحرف كبيرة أو صغيرة في الإنجليزية، أو رمز فترة اليوم الخاص بالإعداد المحلي مثل `'午後'` أو `'م'`. |
| `Z`، `ZZ` | `'-08:00'`، `'-0800'` | إزاحة UTC مع نقطتين أو بدونهما. |
| `z`، `zz` | `'PST'` | الاسم المختصر الموطّن للمنطقة الزمنية. |
| `zzz`، `zzzz` | `'Pacific Standard Time'` | الاسم الكامل الموطّن للمنطقة الزمنية. |
| `X` | `'1794850200'` | طابع عصر Unix بالثواني الصحيحة. |
| `x` | `'1794850200000'` | طابع عصر Unix بالمللي ثانية. |
| `[text]` | `'[at]'` | نص حرفي معزول يُنسخ مباشرةً إلى المخرجات. |
:::

ترمي الحروف غير المعروفة خارج القوسين المعقوفين خطأ [`unknownFormat`](/api/errors/#units-zones-and-formats) بدل طباعة حروف خام. كما ترمي الرموز الملتصقة بحروف ذات نبرات مثل `'às'` أو حروف الساعة المختلطة مثل `'HHhmm'` خطأً أيضًا، بينما يمرّ الحرف `T` المنفرد دون عزل لخدمة طوابع ISO الزمنية.

يرمي طلب حقل لا يحمله النوع خطأ [`unsupportedToken`](/api/errors/#units-zones-and-formats) بدل اختلاق منتصف الليل؛ لذا يفشل تنسيق رموز الساعة مثل `'HH:mm'` على تاريخ تقويمي فورًا.

تصدّر النواة أيضًا [`monthNames()`](/api/month-names/) ونظيرتها `weekdayNames()` (تقبل يوم بداية الأسبوع بالإنجليزية مثل `'monday'`) لبناء ترويسات التقويم الموطّنة وقوائم الأشهر المنسدلة:

```js
import { monthNames, weekdayNames } from 'native-dates';

monthNames('short', 'en-US'); // ['Jan', 'Feb', 'Mar', ...]
weekdayNames('short', undefined, 'en-US'); // ['Sun', 'Mon', 'Tue', ...]
weekdayNames('narrow', 'monday', 'en-US'); // ['Mo', 'Tu', 'We', ...]
```

## تسمية تنسيقاتك الخاصة

سجّل أسماء تنسيقات قابلة لإعادة الاستخدام في [`configure()`](/api/configure/) عندما يكرّر تطبيقك نمط رموز أو كائن خيارات `Intl` عبر عدة واجهات. تعمل الأسماء المخصّصة مع التواريخ والأوقات والتواريخ الجزئية والنطاقات، وتتقدّم على القوالب الجاهزة المدمجة. راجع [التنسيقات المسمّاة](/guides/customization/#named-formats).

## تنسيق النطاقات

ينسّق كل [نطاق](/api/ranges/) القوالب الجاهزة والخيارات عبر `Intl`، فيدمج أجزاء الشهر أو السنة المشتركة تلقائيًا. وينسّق تمرير نمط رموز كلا الطرفين مفصولين بـ `' – '`:

```js
import { dateRange, timeRange } from 'native-dates';

const week = dateRange('2026-09-01', '2026-09-07');
const shift = timeRange('9:00am', '5:00pm');

week.format('medium', 'en-US'); // 'Sep 1 – 7, 2026'
week.format('YYYY-MM-DD'); // '2026-09-01 – 2026-09-07'
shift.format('short', 'en-US'); // '9:00 AM – 5:00 PM'
```

## عبارات الوقت النسبي

استدعِ [`from()`](/api/date-time/#from) أو [`fromNow()`](/api/date-time/#fromnow) على اللحظات الزمنية والتواريخ التقويمية للحصول على عبارات موطّنة عبر منسّق الوقت النسبي في بيئة التشغيل. وتعمل [`formatRelative()`](/api/date-time/#formatrelative) كاسم بديل:

```js
import { date, datetime, now, today } from 'native-dates';

now().minus(5, 'minutes').fromNow('en-US'); // '5 minutes ago'
today().plus(1, 'day').fromNow('en-US'); // 'tomorrow'

const anchor = datetime('2026-11-16T12:00', 'UTC');
anchor.minus(3, 'hours').from(anchor, 'en-US'); // '3 hours ago'
anchor.minus(23, 'hours').from(anchor, 'en-US'); // '1 day ago'

const currentDay = date('2026-11-16');
currentDay.minus(1, 'day').from(currentDay, 'en-US'); // 'yesterday'
currentDay.plus(14, 'days').from(currentDay, 'en-US'); // 'in 2 weeks'
```

تقيس التواريخ التقويمية أيامًا كاملة، لذا تُرجع `from()` و`fromNow()` عبارات مثل «أمس» و«اليوم» و«غدًا» ضمن سبعة أيام. أمّا اللحظات الزمنية فتقيس الوقت المنقضي بالساعة وتلتزم بالأعداد بعد `'now'`؛ إذ قد تظل لحظةٌ قبل 23 ساعة واقعةً في اليوم التقويمي نفسه.

اقرأ [التحليل](/guides/parsing/) تاليًا لتعرف كيف تقرأ النصوص الواردة والقيم الخارجية وتعيدها إلى الشيفرة.
