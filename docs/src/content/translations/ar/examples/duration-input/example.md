عند تمرير نص المستخدم إلى `duration()`، تُقرأ عبارات المدة اليومية بالإنجليزية ونصوص ISO 8601 في قيمة منظّمة واحدة.

بعد ذلك، تكتب `format()` المدة بالكلمات وتحوّل `total('hours')` تلك المدة إلى رقم عشري واحد، بينما يُخرج التحويل إلى نص صيغة ISO 8601 القياسية لقاعدة بيانات أو حمولة API.

يرمي الإدخال غير المقروء خطأً توضّح خاصيته `error.message` (بالإنجليزية في وضع التطوير) النص المخالف وتعرض أمثلة صالحة مباشرةً داخل الصفحة.
