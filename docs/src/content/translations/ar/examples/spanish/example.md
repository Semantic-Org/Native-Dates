يطبّق ضبط `'es'` مرة واحدة في `configure()` التنسيق الإسباني والتحليل المرن بترتيب اليوم أولًا على كامل التطبيق. وتُبقي التواريخ الكاملة أسماء الأيام والأشهر بأحرف صغيرة وتربط اليوم والشهر والسنة بحرف الجر «de».

تدمج نطاقات التواريخ الأجزاء المشتركة عبر `range.format('long')` دون تكرار الإعداد المحلي؛ فيُبقي النطاق داخل مايو «de mayo de 2026» مرة واحدة، بينما يطبع عبور النطاق إلى يونيو اسم كل شهر على طرفي الشرطة.

تقرأ عناوين التقويم `start.yearMonth` لتنسيق «mayo de 2026» مع الإبقاء على أداة الربط «de».

ولأن `'es'` يكتب التواريخ بترتيب اليوم أولًا، يقرأ `date(typed.value, { loose: true })` النص «01/05/2026» بوصفه 1 مايو ويُرجع `null` عند النص غير الصالح.
