## Summary of Maintainer Editing Instincts

1. **Lead with what the developer did or what is missing, not internal plumbing:** Say `"No timezone is configured so cannot compare a CalendarDate to a DateTime"` (`#01a-41`) or `"This mutator wrote to a private field on the client"` (`#01a-14`), rather than opening with an abstract rule lecture.
2. **Teach the concrete mechanism or cost when a warning asks the developer to change their schema or transport:** Instead of just saying primitive fields pack 5–10x smaller, explain *why*: `"Your ephemeral collection '${table.collection}' will send ${named}${rest} as uncompressed JSON over WebTransport datagrams because ${dataType} does not support binary encoding. This increases byte size over the wire by 5-10x. Consider using a field type like String or Number that supports binary encoding"` (`#01b-6`), or why datagram fallback matters (`"susceptible to socket limitations: FIFO, bursting"` in `#s1-d5-27`).
3. **Interpolate the actual runtime value (`${fallback}`, `${dataType}`, `${watermark}`) instead of guessing or listing possibilities:** Never hardcode `"staying on WebSocket"` or `"staying on WebSocket/SSE"` when the client knows which fallback transport is active (`staying on ${fallback}` in `#02-3`, `#02-4`, `#02-5`, `#02-35`, `#01b-13`, `#01b-17`, `#01b-39`).
4. **Cut redundant prefixes when the logger already prints the `[namespace]` badge:** Server errors and logs routed through `createErrors` / `createLogger` already carry `[files]`, `[accounts]`, or `[sync]`, so drop leading `"files: "` or `"createSyncServer: "` prefixes (`#01e-25`, `#01e-26`, `#01e-27`, `#s1-d3-60`, `#s1-d3-66`, `#s1-d5-12`, `#s1-d5-13`).
5. **Prefer full words and direct verbs over abbreviations or jargon:** Write `context` instead of `ctx` (`#s1-d1-39`), `Add` instead of `Implement` (`#s1-d5-12`, `#s1-d5-13`), `retrying on interval` instead of `Will retry on the next interval` (`#s1-d3-4`, `#s1-d3-5`), and `recurses across collections` when describing a recursive dependency chain (`#s1-d5-32`).
6. **Keep filenames and class names short and canonical:** Prefer `persistence-retention.test.js` over `persistence-tombstone-retention.test.js` (`#04a-87`), `element-id-divergence.test.js` over `element-id-divergence-warning.test.js` (`#04a-81`), `export class Cached` in `src/server/cached.js` over `cached-tier.js` (`#05b-46`), and split multi-class files cleanly (`src/query.js` + `src/query-registry.js` in `#05a-1`).
